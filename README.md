# Tidewall /《潮垣》

A 3D open-world sandbox game about a young mage defending their home city from monster tides, built with Godot 4. Playable in English and Simplified Chinese.

一款用 Godot 4 制作的 3D 大世界沙盒游戏:在魔法取代科学的现代世界里,作为一名年轻法师守护家园,抵御兽潮。支持简体中文与英文。
