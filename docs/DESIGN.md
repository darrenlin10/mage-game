# Tidewall /《潮垣》 游戏设计文档

> 状态:**设计中(v0.2 草案)**。本文档是实现的唯一依据;设计有变动先改文档,再改代码。
> 游戏名为暂定名。剧情与设定以中文为源语言;术语的英文对照见第 12 节。

---

## 1. 概述

| 项目 | 内容 |
|---|---|
| 类型 | 3D 第三人称、大世界沙盒探索 + 动作魔法战斗 + 主线剧情 |
| 人数 | 单人(带 NPC 小队) |
| 平台 | 桌面端(Windows / macOS / Linux) |
| 引擎 | Godot 4(GDScript) |
| 语言 | 简体中文 / English,玩家可在首次启动和设置中切换 |
| 题材 | 现代都市魔法:魔法取代了科学,人类城市在结界内抵御荒域异兽 |
| 灵感来源 | 《全职法师》一类的"现代魔法 + 守城"题材。本作世界观、地名、角色、异兽、剧情均为原创,不使用原作的专有设定 |

### 1.1 设计支柱

1. **角色由玩家决定**:元素、天赋带来的构筑方向、小队成员、身份路线、每天做什么,都由玩家选择。
2. **世界可以自由走**:没有等级墙和空气墙,只用危险程度引导;主线不催促玩家。
3. **守护家园是主心骨**:玩家在世界里做的一切(狩猎、研究、建设、结交)最终都会体现在家园的命运上。
4. **元素改变世界**:魔法既是战斗手段,也是通行和解谜手段,元素之间、元素与地形之间会相互反应。
5. **主角是例外,但世界很大**:常人要数人协力才能对付同阶异兽,主角凭天赋与积累可以单挑甚至越阶;但在主角之上,永远还有此刻无法力敌的存在。

### 1.2 篇章结构

故事按"篇"展开,每一篇是一张独立的大地图和一段完整剧情。

| 篇 | 舞台 | 主角位阶 | 状态 |
|---|---|---|---|
| 第一篇《云溪》 | 边境小城云溪及周边荒域 | 见习(下位 → 上位) | **当前实现范围**,本文档详细设计 |
| 后续篇章 | 更辽阔的天地:省城、诸君主的领地、海 | 正阶及以上 | 仅保留大纲(第 17 节),以后再做 |

**当前只做第一篇。** 凡是只在后续篇章才用得到的内容(正阶以上的成长、多数进阶元素内容、其他君主),本文档只定规则,不排进里程碑。

## 2. 世界观

### 2.1 基本设定

- 这是一个科技水平相当于当代的世界,但文明的基础不是物理学而是**灵能**。列车、通讯、电网都由灵能驱动,学校里教灵术就像教数理化。
- 灵能弥漫于大地。长期浸染灵能的动物会异变为**异兽**,对人类聚居地有强烈攻击性。
- 人类生活在由**结界塔**环绕的城市与走廊中。结界外的土地统称**荒域**,约占陆地的三分之二。
- 异兽会不定期成规模地冲击结界,称为**兽潮**。

### 2.2 人与异兽的战力规则

法师的位阶与异兽的等级一一对应(见 3.1 与 4.1),但**同阶之下异兽远强于人**:

- 一只异兽,通常需要 **3–5 名同阶法师协力**才能击败。因此人类以猎队、守备队的形式集体作战,单打独斗被视为送死。
- 高一个大阶的异兽,对低阶法师而言基本不可力敌,只能依靠结界、城防和更高阶的法师。
- 一座城市的安危,取决于它最强的几名法师与它周边最强的异兽之间的差距。

**主角是例外。** 凭借天赋(3.7)与积累(3.8),主角可以单挑同阶异兽;积累深厚、手法高超时可以越一个小阶,极限情况下越一个大阶。具体规则见 9.2。

### 2.3 君主

- 世上存在**多名君主级**异兽,各自盘踞一方(海、高山、荒漠、雪原……),是人类目前无法战胜的存在。人类的版图,实际上是君主们"没兴趣"的那部分土地。
- 云溪所在的海域属于君主**潮主「无岸」**。它栖于外海深处,对小城与其周边的争斗**不屑出手**。
- 但它有一条人类用血换来的规律:**每当沿海有城市破灭(结界全部熄灭),无岸便会现身**,以威压震慑人类、勒令其离开,把那片土地划回自己的疆域。它不屠戮逃走的人,也不容许人留下。二十年前的临江就是这样变成沉城的。
- 其他君主留待后续篇章。

### 2.4 家园:云溪

- 一座河谷中的**边境小城**,人口约八万,三面环山,溪河穿城而过,向东数公里入海。天气好的时候,从东门城墙上能望见海和沉城的轮廓。
- 城市分四个区,每区有一座主结界塔:**东门区**(守备队驻地)、**河港区**(集市与猎人公会)、**学院区**(云溪学院与研究所)、**旧城区**(居民区,主角的家)。
- 云溪的结界塔已服役七十余年,近期开始出现不明原因的闪断。

**云溪的战力**(这决定了第一篇的力量天花板):

| 位阶 | 人数 | 说明 |
|---|---|---|
| 大法师 | 2 | 学院院长**顾松年**(年迈退休,灵核衰退,能动用的灵能已经不多);市长兼守备军统帅**岳峙**(壮年,云溪真正的最强战力) |
| 正阶法师 | 四十余 | 守备队队长、公会资深猎人、学院教授 |
| 见习法师 | 千余 | 守备队士兵、普通猎人、应届毕业生 |
| 其余居民 | — | 启灵后停留在见习下位,灵术只用于生活与工作 |

- 云溪周边荒域的异兽**最高为领主级,且仅有一只**(4.3)。按 2.2 的规则,击败一只领主需要数名大法师协力,而云溪只有两名,其中一名已近枯竭。**云溪打不赢它的领主**,这是第一篇全部紧张感的来源。

### 2.5 历史:临江

二十年前,入海口的大城临江在一夜之间结界全灭,被兽潮吞没;随后无岸自海中现身,幸存者被逼离故土。临江如今称为**沉城**。官方结论是"设备老化"。幸存者散落在云溪各处,其中一些人知道的比官方说法更多。

### 2.6 核心秘密(主线揭示)

结界塔并非单纯的"盾"。它通过抽取周围土地的灵能来维持结界,塔越强,周边荒域越贫瘠,饥饿的异兽便被逼向城墙。**兽潮在一定程度上是结界自己造成的。** 临江的陷落,是当年一位结界工程师试图证明并修正这一点时出的事故。

云溪正在重演这个过程:结界塔越修越强,烬岭深处那只领主的领地越来越贫瘠。

## 3. 魔法体系

### 3.1 启灵与位阶

- 所有学生在 18 岁毕业时参加**启灵仪式**,与一种元素缔结共鸣。游戏从这一天开始。
- 位阶分**大阶**与**小阶**。大阶四级,每个大阶内分**下位、中位、上位**三个小阶。

| 大阶 | English | 常人可用元素数 | 该大阶解锁 |
|---|---|---|---|
| 见习法师 | Initiate | 1 | 主攻、通行、技能;灵纹槽 |
| 正阶法师 | Adept | 2 | 第二元素;更多灵纹槽 |
| 大法师 | Magister | 3 | 第三元素;终结法术;可选进阶元素 |
| 宗师 | Archon | 4 | 第四元素;元素融合技 |

- 宗师之上是否还有位阶,留待后续篇章。
- **大阶突破**时可自选再缔结一种元素。拥有天赋「双生灵核」的角色每次缔结两种(3.7)。

**第一篇的成长范围:见习下位 → 见习上位。** 主角在云溪不会突破到正阶;第一篇结束时停在见习上位圆满,正阶的突破是下一篇的开端。

| 小阶 | 解锁 |
|---|---|
| 见习下位(启灵后) | 主攻法术、通行法术 |
| 见习中位 | 技能法术;每个法术 1 个灵纹槽 |
| 见习上位 | 每个法术 2 个灵纹槽;主攻蓄力强化 |

- **小阶突破条件**:共鸣度达标 + 完成一次试炼任务。共鸣度来自使用法术、击败异兽、学院研习、探索发现,任何玩法都能积累。
- 突破不与主线章节硬绑定,但主线的关键战斗有推荐位阶。

### 3.2 元素

**基础元素**(启灵时可选):

| 元素 | 战斗定位 | 世界用途 |
|---|---|---|
| 火 | 范围伤害、持续灼烧 | 点燃草木、照明、融冰 |
| 霜 | 减速、冻结控制 | 冻结水面成桥、熄火 |
| 雷 | 高速单体、导电连锁 | 为休眠的结界机关充能 |
| 风 | 击退、机动 | 上升气流、滑翔、远跳 |
| 岩 | 护盾、地形制造 | 升起石柱与掩体、堵路 |

**进阶元素**(常人大法师起可选;天赋「异核」可在启灵时选):

| 元素 | 定位 |
|---|---|
| 光 | 治疗、净化、驱散黑暗与潜行异兽 |
| 影 | 潜行、暗杀、短暂隐身 |
| 契 | 召唤与驯服异兽协同作战 |
| 空 | 短距闪现、牵引、放置传送锚点 |

主角在第一篇通常只有一种元素。元素之间的配合主要来自**小队成员**(8.5)和**环境**(3.5)。

### 3.3 法术结构

每种元素提供 4 个法术位,切换当前元素即切换整套法术:

| 法术位 | 说明 | 解锁 |
|---|---|---|
| 主攻 | 低消耗的基础攻击,可蓄力 | 见习下位 |
| 通行 | 兼具战斗与探索用途 | 见习下位 |
| 技能 | 有冷却的强力法术 | 见习中位 |
| 终结 | 高消耗大招,需充能 | 大法师(第一篇中只有顾松年与岳峙能施展) |

基础元素的法术表:

| 元素 | 主攻 | 技能 | 通行 | 终结 |
|---|---|---|---|---|
| 火 | 火弹 | 爆燃(范围爆炸) | 引火(点燃、照明、融冰) | 陨焰 |
| 霜 | 冰锥 | 霜环(周身冻结) | 凝冰(冻结水面/地面) | 极寒领域 |
| 雷 | 电弧 | 连锁闪电 | 充能(激活机关、短暂加速) | 天罚 |
| 风 | 风刃 | 气爆(击退) | 乘风(升空并滑翔) | 龙卷 |
| 岩 | 岩弹 | 岩壁(掩体墙) | 升岩(升起平台) | 地裂 |

进阶元素的法术表在里程碑 4 之前补充到本文档(第一篇只需要它们的主攻、技能、通行)。

### 3.4 灵纹

- 灵纹是嵌入单个法术的改造件,改变法术的行为而不只是数值。例:火弹可嵌"分裂"(一分三)、"滞燃"(落点留下火场)或"贯穿"。
- 灵纹槽数随小阶增加(见 3.1),灵纹可随时在安全区更换。
- 灵纹通过**兽核**与材料制作,或从遗迹、委托、巢主身上获得。
- 由于第一篇主角通常只有一种元素,**灵纹是第一篇构筑多样性的主要来源**:同是火系,嵌不同灵纹可以玩成完全不同的风格。

### 3.5 元素反应

| 条件 | 结果 |
|---|---|
| 湿润 + 雷 | **传导**:伤害在湿润目标之间连锁 |
| 湿润 + 霜 | **冻结**:目标被定身 |
| 火 + 风 | **火旋**:火焰范围扩大并蔓延 |
| 火 + 霜 | **蒸汽**:产生遮蔽视线的雾,解除冻结 |
| 风 + 霜 | **暴雪**:大范围减速 |
| 岩 + 火 | **熔岩**:岩造物变为持续灼烧的地面 |
| 岩 + 雷 | **崩碎**:岩造物炸裂成破片 |

"湿润"来自雨天、水域、沼泽以及部分法术。环境同样参与反应:草地会烧、水面会冻、雨天强化雷而削弱火。反应可以由主角与队友的法术先后命中触发。宗师的**融合技**是把两种已缔结元素的反应做成一个可主动释放的法术(后续篇章)。

### 3.6 角色资源

| 资源 | 用途 | 恢复 |
|---|---|---|
| 生命 | 归零即倒下 | 食物、药剂、光元素、安全区 |
| 灵能 | 施法消耗 | 随时间恢复,战斗外更快 |
| 体力 | 冲刺、闪避、游泳、滑翔 | 停止消耗后快速恢复 |

### 3.7 天赋

- 世上约千人中有一人在启灵时显现**天赋**,称为**天赋者**。主角必定是天赋者。
- 主角的天赋在启灵仪式上**随机抽取一个**,全凭运气,抽到后终身不变。每个新存档重新抽取。
- 所有天赋都只带来优势,没有负面效果。稀有度只影响抽中概率。
- **NPC 也可以是天赋者。** 云溪有少数几位,其中一些可以招募进小队(8.5)。NPC 的天赋与主角共用同一张表。

| 天赋 | 稀有度 | 效果 |
|---|---|---|
| 双生灵核 | 天赐 | 启灵和每次大阶突破时缔结**两种**元素(第一篇即拥有 2 种) |
| 异核 | 天赐 | 启灵时即可选择进阶元素(光、影、契、空) |
| 潮汐灵脉 | 寻常 | 灵能上限 +50%,战斗中的灵能恢复速度与战斗外相同 |
| 共鸣之体 | 寻常 | 元素反应的效果 +50%,持续时间延长 |
| 疾咏 | 寻常 | 技能冷却 −30%,蓄力速度 +50% |
| 灵纹亲和 | 寻常 | 每个法术额外多一个灵纹槽 |
| 残火 | 寻常 | 受到致命伤时保留 1 点生命并短暂无敌,每 5 分钟一次 |
| 兽语 | 寻常 | 无需契元素即可驯服游荡级异兽,驯兽不占小队名额 |
| 界感 | 寻常 | 能看见灵能的流向:隐藏的遗迹、巢穴、异兽弱点会被标出,加固结界塔消耗减少 |

- **概率**:两个天赐天赋各 10%,七个寻常天赋平分其余 80%。*(数值待平衡)*
- **平衡原则**:天赐天赋带来的是广度(更多、更早的元素选择),不是直接的数值碾压;任何天赋都足以通关。
- **剧情联动**:NPC 会对主角的天赋作出反应。破壁会首领渡者本人是「界感」天赋者,他正是因此看见了结界塔抽取土地灵能的事实;主角若同为「界感」,第四章会多出专属对话与线索。

### 3.8 积累

"积累"是同一小阶内的纵向成长,是主角能越阶挑战的另一半原因。常人缺少兽核与天赋,积累有限;主角可以把它堆得很深。

| 积累 | 来源 | 作用 |
|---|---|---|
| 灵核淬炼 | 消耗兽核 | 永久提升灵能上限、恢复速度、法术威力;每个小阶有上限,突破后上限提高 |
| 法术熟练度 | 反复使用该法术 | 降低消耗、缩短蓄力、提高威力,每个法术独立计算 |
| 灵纹 | 制作、遗迹、巢主 | 改变法术行为 |
| 灵具 | 制作、商店、掉落 | 法器、法袍、护符三个部位,带词条 |

一个小阶内四项全部堆满,称为该小阶**圆满**。

## 4. 异兽

### 4.1 等级

异兽等级与法师大阶对应,同样各分下位、中位、上位。

| 等级 | 对应法师位阶 | 说明 |
|---|---|---|
| 游荡级 | 见习 | 普通个体,常成群 |
| 头领级 | 正阶 | 群体首领与巢穴之主,带特殊能力 |
| 领主级 | 大法师 | 统御一片荒域,能驱动兽潮。云溪周边仅一只 |
| 君主级 | 宗师及以上 | 人类目前无法战胜的存在,世上有多名 |

### 4.2 图鉴(第一篇)

| 区域 | 异兽 | 等级 | 行为 | 弱点 |
|---|---|---|---|---|
| 竹海 | 灰牙犬 | 游荡下位 | 成群包抄,嚎叫召集同伴 | 火 |
| 竹海 | 伏竹蛛 | 游荡下位 | 悬在竹冠伏击,吐丝定身 | 火、风 |
| 镜沼 | 苇蜥 | 游荡中位 | 潜伏水下突袭,回水中回血 | 霜(冻住水面)、雷 |
| 镜沼 | 沼灯 | 游荡中位 | 用光诱敌,远程喷吐 | 岩、光 |
| 烬岭 | 甲背兽 | 游荡上位 | 正面无敌的冲锋,撞墙后眩晕露出腹部 | 岩(造墙)、雷 |
| 烬岭 | 烬鹫 | 游荡上位 | 空中俯冲,抓起目标投掷 | 风、雷 |
| 沉城 | 空蛾 | 头领下位 | 只在夜间出现,吸取灵能 | 光、火 |
| 沉城 | 壳居者 | 头领下位 | 伪装成废弃车辆与残骸 | 雷、影 |

### 4.3 巢主、领主与君主

**巢主**是有名字的头领级异兽,各占一处巢穴。对见习的主角而言,讨伐巢主是越一个大阶的挑战,通常需要带满小队。

| 巢主 | 所在 | 等级 | 特点 |
|---|---|---|---|
| 「断尾」 | 竹海 | 头领下位 | 灰牙犬群之首,不断召来犬群,自身极快 |
| 「沉灯」 | 镜沼 | 头领下位 | 巨型沼灯,让整片沼泽陷入黑暗,只剩它的诱光 |
| 「铁脊」 | 烬岭 | 头领中位 | 巨型甲背兽,冲锋会改变地形 |
| 「末班车」 | 沉城 | 头领上位 | 盘踞在一列废弃灵轨列车里的壳居者,可选的极限挑战 |

**领主「衔烛」**(领主中位):盘踞在烬岭深处火山口**烛渊**的巨型火蜥,云溪周边唯一的领主。它的领地被云溪的结界塔逐年抽干,正在一步步逼近云溪。主角在第一篇中**无法对它造成有效伤害**,只能在集体作战中承担任务(10.5)。

**君主·潮主「无岸」**:见 2.3。第一篇中它只在终章现身,不可交战。

### 4.4 掉落

异兽掉落**兽核**(按等级分档,是淬炼、制作与升级的核心资源)和各科专属材料。巢主首次击败必掉一枚稀有灵纹。

## 5. 第一篇地图

### 5.1 规模与结构

- 地图约 8 km × 8 km。云溪位于中部偏西的河谷,溪河向东流经镜沼,在沉城入海。北面是烬岭,西面与南面是竹海。
- 世界使用**固定种子**生成:地形由程序生成,但每个存档的地形和地标位置都相同,地标、巢穴、遗迹为手工布置。
- 无等级墙。玩家第一天就可以走到沉城,只是活不久。

### 5.2 区域

| # | 区域 | 推荐位阶 | 特征 |
|---|---|---|---|
| 0 | 云溪与结界内农田 | 安全 | 主城枢纽:学院、公会、集市、住所 |
| 1 | 竹海 | 见习下位 | 新手森林,视野受限,群居异兽 |
| 2 | 镜沼 | 见习中位 | 浅水与芦苇,伏击,霜/雷解谜 |

| 4 | 沉城 | 正阶(越阶区域) | 半淹没的现代都市废墟,头领级遍布,以潜行与小队协作为主 |
| 5 | 烛渊 | 大法师(禁区) | 领主衔烛的领地,只能远观或潜入边缘 |
| — | 外海 | 不可进入 | 无岸的疆域,始终可以望见 |

### 5.3 哨站与移动

- 地图上有 6 座**哨站**。修复哨站后成为快速旅行点、复活点和补给点。
- 城内与已修复哨站之间可通过**灵轨**快速旅行。灵轨的干线通往省城,是云溪与外界唯一的陆路联系。
- 徒步移动手段:冲刺、游泳,以及各元素的通行法术(滑翔、冰桥、石柱等)。不做自由攀爬。

### 5.4 世界规则

- **昼夜**:一个游戏日约 40 分钟现实时间。夜间异兽更多更强,部分异兽和事件只在夜间出现。
- **天气**:晴、雨、雾、雷暴,影响元素反应和异兽行为。
- **倒下**:在最近的哨站或城内诊所醒来,身上未存放的兽核掉落在倒下地点,可回去拾取一次。

## 6. 第一篇主线:《云溪》

主线共五章。每章结束的围城战由玩家**主动触发**(见 10.3),不设倒计时。

### 6.1 主要角色

| 角色 | 身份 | 位阶 / 元素 | 作用 |
|---|---|---|---|
| 主角 | 云溪学院应届毕业生 | 见习 | 姓名、外观自定义;天赋者 |
| 杜蘅(阿蘅) | 主角的同学与好友 | 见习 / 风 | 第一位队友;其兄长杜若是破壁会成员 |
| 岳峙 | 市长兼守备军统帅 | 大法师 / 岩、火、雷 | 云溪的支柱;主张不惜代价加固结界 |
| 顾松年 | 云溪学院院长 | 大法师 / 光、霜、风 | 年迈,灵核衰退;主角的启灵主持人 |
| 沈砚 | 守备队东门队长 | 正阶 | 严厉的引路人,守备队路线 |
| 白鹭 | 猎人公会老猎人,临江幸存者 | 正阶 | 公会路线;亲眼见过无岸 |
| 祁闻 | 学院结界研究所教授 | 正阶 | 学院路线,逐步接近真相 |
| 渡者 | 破壁会首领,原临江结界工程师 | 正阶 / 天赋「界感」 | 对手,但所言并非全错 |

**破壁会**:一个主张"墙让人类变弱、结界招来兽潮"的秘密团体,暗中破坏云溪的结界塔。

### 6.2 第一章:启灵

毕业、启灵仪式(抽取天赋、选择元素)、与阿蘅随队第一次出城到竹海狩猎。教学章节:移动、施法、元素与环境的互动、小队配合、委托与制作。结尾:东门结界塔在主角眼前闪断了几秒。

### 6.3 第二章:闪断

调查各区结界塔的故障,进入镜沼和烬岭寻找修复用的材料,修复第一座哨站,招募第一批队友。主角在此章选择并加入势力路线(可多选)。结尾:发现闪断是人为破坏。

### 6.4 第三章:初潮

第一次围城战,由数只头领级异兽带领。四个城区同时受袭,主角决定带小队守哪里,其余城区按战前准备自动结算。失守的城区会留下持续的损伤(10.6)。这是一场主角能够左右战局的仗。结尾:破壁会在混乱中现身,线索指向沉城;烬岭方向,烛渊的火光比往年亮得多。

### 6.5 第四章:溯源

随白鹭潜入沉城,还原临江陷落当晚的真相:结界塔的秘密(2.6),以及城破之后自海中升起的无岸。与渡者正面对话,可选择敌对、利用或合作。侦察烛渊,确认衔烛正在离开领地。

回到云溪后,真相摆在所有人面前:**领主将至,云溪守不住。** 岳峙下令经灵轨向省城求援并开始疏散。第五章的目标从"击退"变成"守到能走的人都走完"。

### 6.6 第五章:大潮

衔烛率兽潮压境。主角在备战阶段要表明立场,支持三种守城方案之一:

| 方案 | 提出者 | 做法 | 战局 |
|---|---|---|---|
| **固守** | 岳峙 | 结界全功率运转 | 城墙最硬,撤离窗口最长;但兽潮规模最大,衔烛最为狂暴 |
| **破壁** | 渡者 | 战中分段降低结界功率,把灵能放还土地 | 兽群被分流、规模变小;但结界薄,城区更容易失守 |
| **调律** | 祁闻 | 改造四座塔,使其不再抽取土地 | 需要足够的学院研究进度与沉城资料才会出现;须同时守住四座塔;成功后部分兽群中途退去,是唯一有机会击杀衔烛的方案 |

决战中,岳峙与顾松年合力牵制衔烛,主角与小队负责能够决定战局的任务(10.5)。

**无论哪种方案,云溪的结界都撑不过这一夜。** 衔烛的最后一击(或它死亡时的灵能爆发)摧毁了主塔。四塔熄灭的那一刻,海面隆起,**无岸现身**。它没有出手,只是让所有人明白这片土地已不属于人类,并留下离开的时限。幸存者沿灵轨撤往省城,云溪成为第二座沉城。

### 6.7 第一篇的结局

城必破,但**破成什么样由玩家决定**。结局逐项结算,并写入存档带往下一篇:

| 结算项 | 取决于 |
|---|---|
| 撤离人数 | 四个城区各自守了多久、哨站与灵轨是否畅通 |
| 衔烛的下场 | 击退、重创或击杀(击杀可获得领主兽核,仅"调律"方案且准备充分时可能) |
| 顾松年、岳峙的生死 | 决战中主角任务的完成度 |
| 小队成员的去向 | 各人的羁绊进度与决战中的安排 |
| 主角的立场 | 所支持的方案,决定下一篇开场时各势力对主角的态度 |
| 带走了什么 | 结界研究资料、临江档案、住所里的收藏 |

第一篇以主角站在撤离列车上回望云溪结束。此时主角为见习上位,**"回家"成为贯穿后续篇章的长线目标。**

## 8. 玩家自由度与成长系统

### 8.1 核心循环

**探索 → 狩猎与采集 → 积累与制作(自己、小队和城市)→ 迎接下一次围城**

### 8.2 角色创建

姓名、外观(体型、发型、肤色、服装配色)。不设职业,不设固定性别代词。初始元素在第一章的启灵仪式上由玩家选择,天赋在同一仪式上随机抽取(见 3.7)。

### 8.3 成长维度

| 维度 | 来源 | 作用 |
|---|---|---|
| 天赋 | 启灵时随机抽取 | 贯穿全程的先天优势,决定构筑的起点 |
| 位阶(小阶) | 共鸣度 + 试炼 | 新法术位、灵纹槽、淬炼上限 |
| 积累 | 淬炼、熟练度、灵纹、灵具(3.8) | 同一小阶内的纵向成长,越阶挑战的资本 |
| 小队 | 招募与羁绊(8.5) | 补足元素、触发反应、分担战线 |
| 声望 | 各势力任务 | 商店、蓝图、围城援军、可招募的人 |

不设传统的角色等级和属性点。

### 8.4 沙盒活动

- **委托**:公会板上程序生成的狩猎、采集、护送、清巢任务,无限供应。
- **制作**:用兽核与材料制作灵纹、灵具、药剂、结界部件。
- **住所**:旧城区的一间公寓,可扩建储物、工坊、药圃,可布置。
- **哨站经营**:修复并升级哨站(防御、补给、灵轨站),可派驻队员。
- **探索发现**:遗迹、临江旧档案、隐藏巢穴、观景点,发现本身给共鸣度。

### 8.5 小队

人类以猎队作战是这个世界的常态,主角可以组建自己的队伍。

- **编制**:出城时最多带 **3 名队友**(连主角共四人)。名册可以更大,未出战的队员可派驻哨站或城区,提高该处的防御评分。
- **多样性**:每名队员有自己的元素、位阶、战斗定位、性格,部分是天赋者。队友的元素与主角不同,是第一篇触发元素反应的主要方式。
- **指令**:集火、守位、跟随、自由行动四种简单指令;队友会主动配合主角打出反应。
- **成长**:队友通过同行与个人任务提升羁绊,羁绊解锁其小阶突破和专属能力。队友同样可以装备灵纹与灵具。
- **倒下**:队友在野外倒下后退回城内休养一段时间,不会永久死亡;只有终章的结算可能决定其去向。

首批可招募队员:

| 队员 | 元素 | 位阶 | 天赋 | 定位 | 招募途径 |
|---|---|---|---|---|---|
| 杜蘅(阿蘅) | 风 | 见习下位 | 无 | 机动、击退 | 第一章自动加入 |
| 石敢 | 岩 | 见习下位 | 残火 | 前排、掩体 | 守备队新兵;守备队任务 |
| 陆小满 | 火 | 见习中位 | 共鸣之体 | 范围输出、反应 | 河港区的自由猎人;公会委托 |
| 闻筝 | 雷 | 见习下位 | 界感 | 侦察、破弱点 | 祁闻的助手;学院研究任务 |
| 老秦 | 霜 | 见习上位 | 无 | 控制、经验丰富 | 卡在见习三十年的老猎人;公会声望 |
| 禾生 | 岩 | 见习下位 | 兽语 | 带一只驯服的灰牙犬 | 城外牧场的少年;探索中遇到 |
| 杜若 | 影 | 见习上位 | 异核 | 潜行、暗杀 | 阿蘅的兄长,破壁会成员;第四章视选择而定 |

沈砚、白鹭等正阶角色只在特定任务中临时同行,不能常驻小队。

### 8.6 经济

货币为**灵币**。来源:委托、出售材料。去向:商店、住所、哨站与城防建设。兽核不可用灵币购买,只能靠狩猎获得。

### 8.7 明确不做

多人联机、犯罪/偷窃系统、载具驾驶、自由攀爬、随机生成的世界。

## 9. 战斗设计

### 9.1 基本操作

- **视角与瞄准**:第三人称越肩视角,准星自由瞄准,带轻度辅助瞄准。*(默认方案,待确认)*
- **节奏**:中等速度,强调走位、破解弱点、与队友打出元素反应,而非连招。
- **闪避**:消耗体力的翻滚,带短暂无敌帧。
- **敌人设计原则**:每种异兽至少有一个可以用元素或地形"破解"的行为(见 4.2 的弱点列),而不是只靠堆血量。破解弱点是越阶挑战的关键。

### 9.2 阶差与越阶

**阶差**指双方相差的小阶数(一个大阶 = 三个小阶)。阶位高的一方获得伤害与韧性上的压制,阶差越大压制越强。

| 对手 | 普通法师(无天赋、积累浅) | 主角 |
|---|---|---|
| 同阶同位 | 需 3–5 人协力 | 可以单挑,常规难度 |
| 高一个小阶 | 需一支满编猎队 | 积累充足即可单挑,困难 |
| 高一个大阶 | 需要更高阶的法师带队 | 该小阶圆满、手法高超、并且破解弱点,才有可能单挑,极难;带满小队则是一场正常的首领战 |
| 高两个大阶及以上 | 不可力敌 | 不可力敌,只能在集体作战中承担任务 |

- 主角没有隐藏的数值加成。主角强于常人的部分**全部来自游戏内可见的系统**:天赋、积累、小队,以及玩家自己的操作。
- 普通 NPC 法师按"无天赋、积累浅"设定数值,这样"常人需数人协力"与"主角可以单挑"用的是同一套规则。
- 阶差压制的具体数值在里程碑 1 的战斗原型中调试,目标是让上表每一行的体感成立。

| 主攻(按住蓄力) | 鼠标左键 |
| 精确瞄准 | 鼠标右键 |

## 10. 兽潮与城防

### 10.1 潮位

每个区域有 0–100 的潮位,显示在地图上,表示该区域异兽的密度与强度。潮位由主线章节设定下限,玩家清巢、修哨站可以压低它。

### 10.2 平时的软压力

- 被忽视的哨站会偶尔遭到袭击并降级(失去补给或灵轨功能),**不会永久丢失**,修复即可恢复。派驻队员可以降低被袭击的概率。
- 袭击只在玩家处于城外活动时判定,不会在玩家离线或做长对话时发生。

### 10.3 围城战的触发

围城战由主线任务节点触发:玩家完成章节的前置任务后,在城内主动确认"准备就绪"才开始。*(默认方案,待确认)* 确认前可以无限期自由探索。

### 10.4 围城战的通用流程

1. **备战**:为四座结界塔投入材料加固,布置岩壁与陷阱,通过声望调配援军,安排未出战的队员驻守。每个城区得到一个"防御评分"。
2. **战斗**:数波异兽同时进攻四个城区。主角可带小队在城区间移动,自己选择守哪里;不在场的城区按防御评分与敌方强度自动推进。
3. **结算**:结界塔被摧毁的城区判定为失守。

### 10.5 两场围城战

| | 第三章:初潮 | 第五章:大潮 |
|---|---|---|
| 敌方 | 数只头领级带领的兽群 | 领主衔烛与全部兽潮 |
| 目标 | 守住四座结界塔 | 守到撤离完成 |

| 结果 | 城区的存续与损伤 | 第一篇的结局(6.7) |

### 10.6 失守的后果

- 初潮中失守城区的商店与设施关闭,相关 NPC 受伤暂离,该区潮位下限抬高。
- 损伤是持续的,但可以投入材料与灵币重建。重建程度影响大潮时该城区的防御评分。
- 大潮的结果不可重建,直接写入结局。

## 12. 本地化

- 支持**简体中文**与**English**,首次启动时选择,之后可在设置中随时切换,无需重启。
- **中文是源语言**:剧情、世界观、人物对白、图鉴文本一律先用中文创作,英文版是对中文的翻译。两者有出入时以中文为准。
- 代码与场景中不写死任何面向玩家的文本,全部通过翻译键读取。翻译表使用 CSV,一列一种语言,便于后续增加语言。
- 人名、地名采用"中文名 + 拼音"对应(云溪 / Yunxi);术语采用意译(结界塔 / Ward Tower)。
- 内置支持中文字符的开源字体(Noto Sans SC,OFL 协议)。
- 界面布局需同时容纳两种语言的文本长度。
- 暂不做配音,对话为文本。

## 13. 技术方案

| 项目 | 方案 |
|---|---|
| 引擎 | Godot 4 最新稳定版,开工时锁定具体版本号并写入本文档 |
| 脚本 | GDScript(不用 C#,减少依赖,导出更简单) |
| 渲染 | Forward+;为低配机器保留 Compatibility 渲染器选项 |
| 性能目标 | 1080p / 60 fps,GTX 1060 级别显卡 |
| 地形 | 分块高度图,噪声 + 区域蒙版生成,后台线程生成网格与碰撞,按距离分级细节 |
| 植被与散布物 | MultiMesh 批量实例,按区块流式加载 |
| 角色 | CharacterBody3D + 弹簧臂第三人称相机 |
| 异兽与队友 AI | 状态机 + 转向行为(野外);城内使用导航网格 |
| 数据 | 法术、异兽、物品、任务、灵纹、天赋、队员全部做成 Resource 数据文件,逻辑与数据分离 |
| 篇章 | 每一篇是独立的地图与内容包,共用同一套系统;存档记录篇章结算结果以便继承 |
| 存档 | JSON 存于 `user://`,多存档位,进出安全区与关键节点自动存档 |
| 测试 | 无头模式跑单元测试(战斗公式、阶差、元素反应、天赋抽取、存档读写、翻译键完整性) |

### 开发方式

场景与脚本全部以文本形式编写并纳入版本管理,不依赖在编辑器里手工摆放。画面和手感的验收需要在本地运行 Godot 实机试玩。

## 14. 美术与音频

- **美术**:风格化低多边形。地形、建筑、植被以程序生成和基础几何体为主,可按需引入 CC0 协议的免费模型包。*(默认方案,待确认)*
- **色彩**:每个区域一套主色调(竹海青绿、镜沼银灰、烬岭赭红、沉城青蓝、烛渊暗红),元素特效使用高饱和度的固定配色以便识别。
- **城市观感**:现代东亚小城(公寓楼、骑楼、电线杆、便利店)叠加灵能设施(结界塔、灵轨、发光的灵纹路灯)。
- **尺度感**:领主与君主必须在体量上让人一眼明白"打不过"。无岸现身是全篇的视觉高潮。
- **音频**:首版使用 CC0 音效与环境音;音乐后置。
