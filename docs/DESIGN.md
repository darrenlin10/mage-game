## 1. 概述

| 项目 | 内容 |
|---|---|
| 类型 | 3D 第三人称、大世界沙盒探索 + 动作魔法战斗 + 主线剧情 |
| 人数 | 单人(带 NPC 小队) |
| 平台 | 桌面端(Windows / macOS / Linux) |
| 引擎 | Godot 4(GDScript) |
| 语言 | 简体中文 / English,玩家可在首次启动和设置中切换 |
| 题材 | 现代都市魔法:魔法取代了科学,人类城市在结界内抵御荒域异兽 |
| 灵感来源 | 《全职法师》一类的"现代魔法 + 守城"题材。本作世界观、地名、角色、异兽、剧情均为原创,不使用原作的专有设定 |

### 1.1 设计支柱

1. **角色由玩家决定**:元素、天赋带来的构筑方向、小队成员、身份路线、每天做什么,都由玩家选择。
2. **世界可以自由走**:没有等级墙和空气墙,只用危险程度引导;主线不催促玩家。
3. **守护家园是主心骨**:玩家在世界里做的一切(狩猎、研究、建设、结交)最终都会体现在家园的命运上。
4. **元素改变世界**:魔法既是战斗手段,也是通行和解谜手段,元素之间、元素与地形之间会相互反应。
5. **主角是例外,但世界很大**:常人要数人协力才能对付同阶异兽,主角凭天赋与积累可以单挑甚至越阶;但主角在宏观上并不强,改变不了一座城的存亡。
6. **选择塑造世界线**:主角真正能撬动世界的是抉择。探索途中的事件要求玩家做决定,后果可能在很久以后才到来,有名有姓的人会因此活下来或死去。

### 1.2 篇章结构

故事按"篇"展开,每一篇是一张独立的大地图和一段完整剧情。

| 篇 | 舞台 | 主角位阶 | 状态 |
|---|---|---|---|
| 第一篇《云溪》 | 边境小城云溪及周边荒域 | 见习(下位 → 上位) | **当前实现范围**,本文档详细设计 |
| 后续篇章 | 更辽阔的天地:超级城市衡州、诸君主的领地、海 | 正阶及以上 | 仅保留大纲(第 17 节),以后再做 |

**当前只做第一篇。** 凡是只在后续篇章才用得到的内容(正阶以上的成长、多数进阶元素内容、其他君主),本文档只定规则,不排进里程碑。

## 2. 世界观

### 2.1 基本设定

- 这是一个科技水平相当于当代的世界,但文明的基础不是物理学而是**灵能**。列车、通讯、电网都由灵能驱动,学校里教灵术就像教数理化。
- 灵能弥漫于大地。长期浸染灵能的动物会异变为**异兽**,对人类聚居地有强烈攻击性。
- 人类生活在由**结界塔**环绕的城市与走廊中。结界外的土地统称**荒域**,约占陆地的三分之二。
- 异兽会不定期成规模地冲击结界,称为**兽潮**。

### 2.2 人与异兽的战力规则

法师的位阶与异兽的等级一一对应(见 3.1 与 4.1),但**同阶之下异兽远强于人**:

- 一只异兽,通常需要 **3–5 名同阶法师协力**才能击败。因此人类以猎队、守备队的形式集体作战,单打独斗被视为送死。
- 高一个大阶的异兽,对低阶法师而言基本不可力敌,只能依靠结界、城防和更高阶的法师。**每一个大阶的差距都是天差地别**,而且位阶越高,这道鸿沟越深。
- 一座城市的安危,取决于它最强的几名法师与它周边最强的异兽之间的差距。正阶与见习在一条街、一段城墙上能决定胜负,在整场战争的尺度上无足轻重。

**主角是例外。** 凭借天赋(3.7)与积累(3.8),主角可以单挑同阶异兽;积累深厚、手法高超时可以越一个小阶,极限情况下能与高一个大阶的对手周旋。越阶随位阶提高而越来越难。具体规则见 9.2。

### 2.3 君主

- 世上存在**多名君主级**异兽,各自盘踞一方(海、高山、荒漠、雪原……),是人类目前无法战胜的存在。人类的版图,实际上是君主们"没兴趣"的那部分土地。
- 人类的**宗师**极其稀少,几乎每一位都坐镇一座**超级城市**,牵制着与自己对应的那名君主,无法抽身。因此小城遇险时,超级城市能派出的援军只有少数几名大法师。
- 云溪所在的海域属于君主**潮主「无岸」**。它栖于外海深处,对小城与其周边的争斗**不屑出手**。
- 但它有一条人类用血换来的规律:**每当沿海有城市破灭(结界全部熄灭),无岸便会现身**,以威压震慑人类、勒令其离开,把那片土地划回自己的疆域。它不屠戮逃走的人,也不容许人留下。二十年前的临江就是这样变成沉城的。
- 其他君主留待后续篇章。

### 2.4 家园:云溪

- 一座河谷中的**边境小城**,人口约八万,三面环山,溪河穿城而过,向东数公里入海。天气好的时候,从东门城墙上能望见海和沉城的轮廓。
- 城市分四个区,每区有一座主结界塔:**东门区**(守备队驻地)、**河港区**(集市与猎人公会)、**学院区**(云溪学院与研究所)、**旧城区**(居民区,主角的家)。
- 云溪的结界塔已服役七十余年,近期开始出现不明原因的闪断。
- 离云溪最近的超级城市是**衡州**,经灵轨干线相连。云溪没有大学,学生高考后都要去往大城市。

**云溪的战力**(这决定了第一篇的力量天花板):

| 位阶 | 人数 | 说明 |
|---|---|---|
| 大法师 | 2 | 学院院长**顾松年**(年迈退休,灵核衰退,能动用的灵能已经不多);市长兼守备军统帅**岳峙**(壮年,云溪真正的最强战力) |
| 正阶法师 | 四十余 | 守备队队长、公会资深猎人、学院教师 |
| 见习法师 | 千余 | 守备队士兵、普通猎人、应届毕业生 |
| 其余居民 | — | 启灵后停留在见习下位,灵术只用于生活与工作 |

- 云溪周边荒域的异兽**最高为领主级,且仅有一只**(4.3)。按 2.2 的规则,击败一只领主需要数名大法师协力,而云溪只有两名,其中一名已近枯竭。单是这一只领主,就要两名大法师拼死才拖得住。**云溪守不住**,这是第一篇的既定结局。

### 2.5 历史:临江

二十年前,入海口的大城临江在一夜之间结界全灭,被兽潮吞没;随后无岸自海中现身,幸存者被逼离故土。临江如今称为**沉城**。官方结论是"设备老化"。幸存者散落在云溪各处,其中一些人知道的比官方说法更多。

### 2.6 核心秘密(主线揭示)

结界塔并非单纯的"盾"。它通过抽取周围土地的灵能来维持结界,塔越强,周边荒域越贫瘠,饥饿的异兽便被逼向城墙。**兽潮在一定程度上是结界自己造成的。** 临江的陷落,是当年一位结界工程师试图证明并修正这一点时出的事故。

云溪正在重演这个过程:结界塔越修越强,烬岭深处那只领主的领地越来越贫瘠。

### 2.7 教育与高考

| 年龄 | 阶段 | 内容 |
|---|---|---|
| 15–16 岁 | 高一 | 一年理论学习。学年末举行**启灵仪式**与理论结业考 |
| 16–18 岁 | 高二、高三 | 两年修炼法术:实训、狩猎、考核 |
| 18 岁 | **高考** | **文考**(理论)+ **武考**(实战),成绩决定去哪座城市的学府 |

- 云溪学院是云溪唯一的学校,设高中部与结界研究所。
- **天赋者一经显现就会被挖走。** 超级城市的招生官常年在各地的启灵仪式上守着,天赋者当场拿到预录取,前途无量。小城因此几乎留不住天赋者。

### 2.8 人类的叛徒:归潮

- **归潮**是一个信奉君主的秘密组织,认为沿海本就该还给海,人类的城市破灭得越早,死的人越少。
- 他们做两件事:破坏结界,以及**猎杀年轻的天赋者**(称为"拔苗")。启灵档案是他们最想要的东西。
- 因此天赋在这个世界上既是通行证,也是催命符。**显现天赋之后说还是不说**,是每个天赋者都要面对的抉择,也是主角的第一个重大抉择(见剧情大纲第 5 节)。
- 归潮与破壁会不是一回事。破壁会想修正结界以救人;归潮暗中资助并利用他们。

### 2.9 主角:穿越者

- 主角来自一个没有灵能的现代世界,在启灵前一个月醒来,成了云溪学院一名高一学生。主角对这个世界一无所知,序章既是剧情也是教程。
- 穿越是主角的又一个秘密。它与主角的天赋、与终章无岸的那一瞥之间的关系,留待后续篇章。

## 3. 魔法体系

### 3.1 启灵与位阶

- 所有学生在 16 岁、高一学年末参加**启灵仪式**,与一种元素缔结共鸣。游戏从启灵前一个月开始。
- 位阶分**大阶**与**小阶**。大阶四级,每个大阶内分**下位、中位、上位**三个小阶。

| 大阶 | English | 常人可用元素数 | 该大阶解锁 |
|---|---|---|---|
| 见习法师 | Initiate | 1 | 主攻、通行、技能;灵纹槽 |
| 正阶法师 | Adept | 2 | 第二元素;更多灵纹槽 |
| 大法师 | Magister | 3 | 第三元素;终结法术;可选进阶元素 |
| 宗师 | Archon | 4 | 第四元素;元素融合技 |

- 宗师之上是否还有位阶,留待后续篇章。
- **大阶突破**时可自选再缔结一种元素。拥有天赋「双生灵核」的角色每次缔结两种(3.7)。

**第一篇的成长范围:见习下位 → 见习上位。** 主角在云溪的两年里不会突破到正阶;正阶的突破是下一篇的开端。主角离开云溪时积累到什么程度,取决于玩家这两年的努力。

| 小阶 | 解锁 |
|---|---|
| 见习下位(启灵后) | 主攻法术、通行法术 |
| 见习中位 | 技能法术;每个法术 1 个灵纹槽 |
| 见习上位 | 每个法术 2 个灵纹槽;主攻蓄力强化 |

- **小阶突破条件**:共鸣度达标 + 完成一次试炼任务。共鸣度来自使用法术、击败异兽、学院研习、探索发现,任何玩法都能积累。
- 突破不与主线章节硬绑定,但主线的关键战斗有推荐位阶。

### 3.2 元素

**基础元素**(启灵时可选):

| 元素 | 战斗定位 | 世界用途 |
|---|---|---|
| 火 | 范围伤害、持续灼烧 | 点燃草木、照明、融冰 |
| 霜 | 减速、冻结控制 | 冻结水面成桥、熄火 |
| 雷 | 高速单体、导电连锁 | 为休眠的结界机关充能 |
| 风 | 击退、机动 | 上升气流、滑翔、远跳 |
| 岩 | 护盾、地形制造 | 升起石柱与掩体、堵路 |

**进阶元素**(常人大法师起可选;天赋「异核」可在启灵时选):

| 元素 | 定位 |
|---|---|
| 光 | 治疗、净化、驱散黑暗与潜行异兽 |
| 影 | 潜行、暗杀、短暂隐身 |
| 契 | 召唤与驯服异兽协同作战 |
| 空 | 短距闪现、牵引、放置传送锚点 |

**元素的世俗评价。** 基础元素在世人眼中有高下之分,标准是正面杀伤力:

| 评价 | 元素 | 世人的看法 |
|---|---|---|
| 上品 | 雷、火 | 攻伐最强,名校与军方争抢 |
| 中品 | 霜、风 | 控制与辅助,中规中矩 |
| 下品 | 岩 | "修城墙的",被视为工程系 |

- 世俗评价影响分班、资源配给、武考的基准分以及旁人的态度,**不影响实际强度**:五种元素在玩家手中是平衡的。这个世界的主流战法是单元素齐射,对元素之间的配合研究很浅;主角带着另一个世界的思路,看得到别人看不到的用法。
- 觉醒上品元素更受重视,也更引人注目;觉醒下品元素无人问津,也无人打扰。这与"天赋说不说"是同一类取舍。

**元素的选择。** 常人启灵时只有一种元素回应。主角启灵时有数种元素同时回应,可以**选择回应哪一种**,这是玩家选择初始元素的时刻;旁人只看得到最后亮起的那一种。

主角在第一篇通常只有一种元素。元素之间的配合主要来自**小队成员**(8.5)和**环境**(3.5)。

### 3.3 法术结构

每种元素提供 4 个法术位,切换当前元素即切换整套法术:

| 法术位 | 说明 | 解锁 |
|---|---|---|
| 主攻 | 低消耗的基础攻击,可蓄力 | 见习下位 |
| 通行 | 兼具战斗与探索用途 | 见习下位 |
| 技能 | 有冷却的强力法术 | 见习中位 |
| 终结 | 高消耗大招,需充能 | 大法师(第一篇中只有顾松年与岳峙能施展) |

基础元素的法术表:

| 元素 | 主攻 | 技能 | 通行 | 终结 |
|---|---|---|---|---|
| 火 | 火弹 | 爆燃(范围爆炸) | 引火(点燃、照明、融冰) | 陨焰 |
| 霜 | 冰锥 | 霜环(周身冻结) | 凝冰(冻结水面/地面) | 极寒领域 |
| 雷 | 电弧 | 连锁闪电 | 充能(激活机关、短暂加速) | 天罚 |
| 风 | 风刃 | 气爆(击退) | 乘风(升空并滑翔) | 龙卷 |
| 岩 | 岩弹 | 岩壁(掩体墙) | 升岩(升起平台) | 地裂 |

进阶元素的法术表在里程碑 4 之前补充到本文档(第一篇只需要它们的主攻、技能、通行)。

### 3.4 灵纹

- 灵纹是嵌入单个法术的改造件,改变法术的行为而不只是数值。例:火弹可嵌"分裂"(一分三)、"滞燃"(落点留下火场)或"贯穿"。
- 灵纹槽数随小阶增加(见 3.1),灵纹可随时在安全区更换。
- 灵纹通过**兽核**与材料制作,或从遗迹、委托、巢主身上获得。
- 由于第一篇主角通常只有一种元素,**灵纹是第一篇构筑多样性的主要来源**:同是火系,嵌不同灵纹可以玩成完全不同的风格。

### 3.5 元素反应

| 条件 | 结果 |
|---|---|
| 湿润 + 雷 | **传导**:伤害在湿润目标之间连锁 |
| 湿润 + 霜 | **冻结**:目标被定身 |
| 火 + 风 | **火旋**:火焰范围扩大并蔓延 |
| 火 + 霜 | **蒸汽**:产生遮蔽视线的雾,解除冻结 |
| 风 + 霜 | **暴雪**:大范围减速 |
| 岩 + 火 | **熔岩**:岩造物变为持续灼烧的地面 |
| 岩 + 雷 | **崩碎**:岩造物炸裂成破片 |

"湿润"来自雨天、水域、沼泽以及部分法术。环境同样参与反应:草地会烧、水面会冻、雨天强化雷而削弱火。反应可以由主角与队友的法术先后命中触发。宗师的**融合技**是把两种已缔结元素的反应做成一个可主动释放的法术(后续篇章)。

### 3.6 角色资源

| 资源 | 用途 | 恢复 |
|---|---|---|
| 生命 | 归零即倒下 | 食物、药剂、光元素、安全区 |
| 灵能 | 施法消耗 | 随时间恢复,战斗外更快 |
| 体力 | 冲刺、闪避、游泳、滑翔 | 停止消耗后快速恢复 |

### 3.7 天赋

- **天赋**极其罕见:寻常天赋**万里挑一**,天赐天赋更是百万中无一。拥有天赋的人称为**天赋者**。主角必定是天赋者。
- 主角的天赋在启灵仪式上**随机抽取一个**,全凭运气,抽到后终身不变。每个新存档重新抽取。
- 所有天赋都只带来优势,没有负面效果。稀有度只影响抽中概率。
- 启灵石只测得出元素,测不出天赋。天赋显现时只有本人知道,**是否上报由本人决定**(2.8)。
- **NPC 也可以是天赋者**,与主角共用同一张表。但天赋者一经显现就被超级城市带走,留在云溪的只有隐瞒者与漏网者,寥寥数人,极难结识(8.5)。

| 天赋 | 稀有度 | 效果 |
|---|---|---|
| 双生灵核 | 天赐 | 启灵和每次大阶突破时缔结**两种**元素(第一篇即拥有 2 种) |
| 异核 | 天赐 | 启灵时即可选择进阶元素(光、影、契、空) |
| 潮汐灵脉 | 寻常 | 灵能上限 +50%,战斗中的灵能恢复速度与战斗外相同 |
| 共鸣之体 | 寻常 | 元素反应的效果 +50%,持续时间延长 |
| 疾咏 | 寻常 | 技能冷却 −30%,蓄力速度 +50% |
| 灵纹亲和 | 寻常 | 每个法术额外多一个灵纹槽 |
| 残火 | 寻常 | 受到致命伤时保留 1 点生命并短暂无敌,每 5 分钟一次 |
| 兽语 | 寻常 | 无需契元素即可驯服游荡级异兽,驯兽不占小队名额 |
| 界感 | 寻常 | 能看见灵能的流向:隐藏的遗迹、巢穴、异兽弱点会被标出,加固结界塔消耗减少 |

- **概率**:两个天赐天赋各 10%,七个寻常天赋平分其余 80%。*(数值待平衡)*
- **平衡原则**:天赐天赋带来的是广度(更多、更早的元素选择),不是直接的数值碾压;任何天赋都足以通关。
- **剧情联动**:NPC 会对主角的天赋作出反应。破壁会首领渡者本人是「界感」天赋者,他正是因此看见了结界塔抽取土地灵能的事实;主角若同为「界感」,第四章会多出专属对话与线索。

### 3.8 积累

"积累"是同一小阶内的纵向成长,是主角能越阶挑战的另一半原因。常人缺少兽核与天赋,积累有限;主角可以把它堆得很深。

| 积累 | 来源 | 作用 |
|---|---|---|
| 灵核淬炼 | 消耗兽核 | 永久提升灵能上限、恢复速度、法术威力;每个小阶有上限,突破后上限提高 |
| 法术熟练度 | 反复使用该法术 | 降低消耗、缩短蓄力、提高威力,每个法术独立计算 |
| 灵纹 | 制作、遗迹、巢主 | 改变法术行为 |
| 灵具 | 制作、商店、掉落 | 法器、法袍、护符三个部位,带词条 |

一个小阶内四项全部堆满,称为该小阶**圆满**。

## 8. 玩家自由度与成长系统

### 8.1 核心循环

**探索 → 狩猎与采集 → 积累与制作(自己、小队和城市)→ 迎接下一次围城**

### 8.2 角色创建

在序章开场时进行:**性别(男 / 女,自由选择)**、姓名、外观(体型、发型、肤色、服装配色)。性别影响角色模型与对白中的称呼,不影响数值与剧情分支。不设职业。初始元素在第一章的启灵仪式上由玩家选择,天赋在同一仪式上随机抽取(见 3.7)。

### 8.3 成长维度

| 维度 | 来源 | 作用 |
|---|---|---|
| 天赋 | 启灵时随机抽取 | 贯穿全程的先天优势,决定构筑的起点 |
| 位阶(小阶) | 共鸣度 + 试炼 | 新法术位、灵纹槽、淬炼上限 |
| 积累 | 淬炼、熟练度、灵纹、灵具(3.8) | 同一小阶内的纵向成长,越阶挑战的资本 |
| 小队 | 招募与羁绊(8.5) | 补足元素、触发反应、分担战线 |
| 声望 | 各势力任务 | 商店、蓝图、围城援军、可招募的人 |

不设传统的角色等级和属性点。

### 8.4 沙盒活动

- **委托**:公会板上程序生成的狩猎、采集、护送、清巢任务,无限供应。
- **制作**:用兽核与材料制作灵纹、灵具、药剂、结界部件。
- **家**:旧城区"晚来面馆"楼上,与母亲、妹妹同住。自己的房间可扩充储物与工作台;在面馆帮忙、陪伴家人是日常活动的一部分。
- **学业**:理论课、实训、期中期末考核。课上学到的知识进入图鉴,并计入高考文考。
- **哨站经营**:修复并升级哨站(防御、补给、灵轨站),可派驻队员。
- **探索发现**:遗迹、临江旧档案、隐藏巢穴、观景点,发现本身给共鸣度。

### 8.5 小队

人类以猎队作战是这个世界的常态。

- **编制由玩家决定**:猎队的规矩是满编出行,出城最多带 **3 名队友**(连主角共四人)。但主角可以只带一两人,或者独行。
- **取舍**:人多则稳,但兽核与共鸣度按出战人数分配;独行所得全归自己,积累最快,也最危险。
- **多样性**:每名队员有自己的元素、位阶、战斗定位、性格。队友的元素与主角不同,是第一篇触发元素反应的主要方式。
- **指令**:集火、守位、跟随、自由行动四种简单指令;队友会主动配合主角打出反应。
- **成长**:队友通过同行与个人事件提升羁绊,羁绊解锁其小阶突破和专属能力。队友同样可以装备灵纹与灵具。
- **队友会死。** 队友倒地后进入濒死状态,限时内救起则重伤、回城休养;救不起,或主角撤退时把他留下,即**永久阵亡**。越阶讨伐与高潮位区域风险最高。阵亡会被他的家人、同乡和其他队友记住。
- 未出战的队员可派驻哨站或城区,提高该处的防御评分。

### 8.6 事件与世界线

- 自由探索时会触发**事件**,要求玩家当场做出选择。事件分三类:**必出**(主线固定)、**条件**(满足条件即发生)、**概率**(按区域、时间与世界线状态随机)。
- 一个事件包含:触发条件、情境、2–4 个选项、即时结果、世界线标记。部分选项只在拥有特定元素、天赋、队友或声望时出现。
- 选择可能意味着战斗、危险、奖励或牺牲。后果不一定当场显现,可能在几章之后才到来。
- 概率事件一旦触发,其内容在该存档中即已确定,不能靠读档刷结果。
- **世界线变量**:暴露度、疏散准备度、城防、归潮渗透、每个人物的状态、主角的立场。定义与事件示例见剧情大纲第 11 节。

### 8.7 经济

货币为**灵币**。来源:委托、出售材料。去向:商店、住所、哨站与城防建设。兽核不可用灵币购买,只能靠狩猎获得。

### 8.8 明确不做

多人联机、犯罪/偷窃系统、载具驾驶、自由攀爬、随机生成的世界。

## 9. 战斗设计

### 9.1 基本操作

- **视角与瞄准**:第三人称越肩视角,准星自由瞄准,带轻度辅助瞄准。*(默认方案,待确认)*
- **节奏**:中等速度,强调走位、破解弱点、与队友打出元素反应,而非连招。
- **闪避**:消耗体力的翻滚,带短暂无敌帧。
- **敌人设计原则**:每种异兽至少有一个可以用元素或地形"破解"的行为(见 4.2 的弱点列),而不是只靠堆血量。破解弱点是越阶挑战的关键。

### 9.2 阶差与越阶

**阶差**指双方相差的小阶数(一个大阶 = 三个小阶)。阶位高的一方获得伤害与韧性上的压制,阶差越大压制越强。

| 对手 | 普通法师(无天赋、积累浅) | 主角 |
|---|---|---|
| 同阶同位 | 需 3–5 人协力 | 可以单挑,常规难度 |
| 高一个小阶 | 需一支满编猎队 | 积累充足即可单挑,困难 |
| 高一个大阶 | 需要更高阶的法师带队 | 该小阶圆满、手法高超时可以**周旋、拖住**,难以击杀;带满小队、做足准备并破解弱点才有击杀的可能,且队友有阵亡风险 |
| 高两个大阶及以上 | 不可力敌 | 不可力敌,只能在集体作战中承担任务 |

- **越阶随位阶提高而越来越难。** 见习对头领级的差距已是极限;正阶对领主级、大法师对君主级的差距逐级拉大,到后来不再是技巧可以弥补的。
- 主角没有隐藏的数值加成。主角强于常人的部分**全部来自游戏内可见的系统**:天赋、积累、小队,以及玩家自己的操作。
- 普通 NPC 法师按"无天赋、积累浅"设定数值,这样"常人需数人协力"与"主角可以单挑"用的是同一套规则。
- 阶差压制的具体数值在里程碑 1 的战斗原型中调试,目标是让上表每一行的体感成立。

## 10. 兽潮与城防

### 10.1 潮位

每个区域有 0–100 的潮位,显示在地图上,表示该区域异兽的密度与强度。潮位由主线章节设定下限,玩家清巢、修哨站可以压低它。

### 10.2 平时的软压力

- 被忽视的哨站会偶尔遭到袭击并降级(失去补给或灵轨功能),**不会永久丢失**,修复即可恢复。派驻队员可以降低被袭击的概率。
- 袭击只在玩家处于城外活动时判定,不会在玩家离线或做长对话时发生。

### 10.3 围城战的触发

围城战由主线任务节点触发:玩家完成章节的前置任务后,在城内主动确认"准备就绪"才开始。*(默认方案,待确认)* 确认前可以无限期自由探索。唯一的例外是终章"灭城之夜":一夜分六个时段,真实计时。

### 10.4 围城战的通用流程

1. **备战**:为四座结界塔投入材料加固,布置岩壁与陷阱,通过声望调配援军,安排未出战的队员驻守。每个城区得到一个"防御评分"。
2. **战斗**:数波异兽同时进攻四个城区。主角可带小队在城区间移动,自己选择守哪里;不在场的城区按防御评分与敌方强度自动推进。
3. **结算**:结界塔被摧毁的城区判定为失守。

### 10.5 两场围城战

| | 第三章:初潮 | 终章:大潮 |
|---|---|---|
| 起因 | 归潮内应瘫痪两座结界塔 | 领主衔烛出渊 |
| 敌方 | 数只头领级带领的兽群 | 衔烛、数十只头领级与全部兽潮 |
| 人类一方 | 岳峙与正阶们对付头领,见习守街巷 | 两名大法师拼死拖住衔烛;全城死守、疏散平民、等待衡州的三名大法师 |
| 目标 | 守住四座结界塔 | 没有胜利条件。尽可能多的人上车 |
| 主角的作用 | 带小队守一个城区。**这一仗主角的努力能保住城区** | 清理游荡级、拖住头领级、在各告急点之间取舍。影响的是谁活下来,不是战局 |
| 结果 | 城区的存续与损伤 | 第一篇的结算 |

### 10.6 失守的后果

- 初潮中失守城区的商店与设施关闭,相关 NPC 受伤暂离,该区潮位下限抬高。
- 损伤是持续的,但可以投入材料与灵币重建。重建程度影响大潮时该城区的防御评分。
- 大潮之后没有重建。结果直接写入第一篇的结算。

## 12. 本地化

- 支持**简体中文**与**English**,首次启动时选择,之后可在设置中随时切换,无需重启。
- **中文是源语言**:剧情、世界观、人物对白、图鉴文本一律先用中文创作,英文版是对中文的翻译。两者有出入时以中文为准。
- 代码与场景中不写死任何面向玩家的文本,全部通过翻译键读取。翻译表使用 CSV,一列一种语言,便于后续增加语言。
- 人名、地名采用"中文名 + 拼音"对应(云溪 / Yunxi);术语采用意译(结界塔 / Ward Tower)。
- 内置支持中文字符的开源字体(Noto Sans SC,OFL 协议)。
- 界面布局需同时容纳两种语言的文本长度。
- 暂不做配音,对话为文本。

## 14. 美术与音频

- **美术**:风格化低多边形。地形、建筑、植被以程序生成和基础几何体为主,可按需引入 CC0 协议的免费模型包。*(默认方案,待确认)*

- **城市观感**:现代东亚小城(公寓楼、骑楼、电线杆、便利店)叠加灵能设施(结界塔、灵轨、发光的灵纹路灯)。
- **尺度感**:领主与君主必须在体量上让人一眼明白"打不过"。无岸现身是全篇的视觉高潮。
- **音频**:首版使用 CC0 音效与环境音;音乐后置。
