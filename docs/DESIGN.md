## 1. 概述

| 项目 | 内容 |
|---|---|
| 类型 | 3D 第三人称、大世界沙盒探索 + 动作战斗 + 修炼养成 + 主线剧情 |
| 人数 | 单人(带 NPC 小队) |
| 平台 | 桌面端(Windows / macOS / Linux) |
| 引擎 | Godot 4(GDScript) |
| 语言 | 简体中文 / English,玩家可在首次启动和设置中切换 |
| 题材 | 现代都市灵能:灵能取代了科学,人类城市在结界内抵御荒域异兽 |
| 灵感来源 | 《全职法师》一类的"现代魔法 + 守城"题材。本作世界观、地名、角色、异兽、剧情均为原创,不使用原作的专有设定 |

### 1.1 设计支柱

1. **起点靠运气,路由玩家走**:启灵时觉醒什么元素、显现什么天赋全凭运气;此后怎么修炼、往哪个方向觉醒、带谁同行、走哪条身份路线、每天做什么,都由玩家决定。
2. **世界可以自由走**:没有等级墙和空气墙,只用危险程度引导;主线不催促玩家。
3. **守护家园是主心骨**:玩家在世界里做的一切(狩猎、研究、建设、结交)最终都会体现在家园的命运上。
4. **元素改变世界**:灵能技既是战斗手段,也是通行和解谜手段,元素之间、元素与地形之间会相互反应。
7. **修为是亲手练出来的**:没有一键修炼。吞吐灵能、链接灵链、释放灵能技都要玩家亲自动手,练得越多越快;只有修到下一阶段,上一阶段的功夫才变成本能。
8. **资源要拿命去换**:修炼所需的灵晶稀缺,好东西市面上没有卖,只能进荒域去找。
5. **主角是例外,但世界很大**:常人要数人协力才能对付同阶异兽,主角凭天赋与积累可以单挑甚至越阶;但主角在宏观上并不强,改变不了一座城的存亡。
6. **选择塑造世界线**:主角真正能撬动世界的是抉择。探索途中的事件要求玩家做决定,后果可能在很久以后才到来,有名有姓的人会因此活下来或死去。

### 1.2 篇章结构

故事按"篇"展开,每一篇是一张独立的大地图和一段完整剧情。

| 篇 | 舞台 | 主角位阶 | 状态 |
|---|---|---|---|
| 第一篇《云溪》 | 边境小城云溪及周边荒域 | 见习(下位 → 上位) | **当前实现范围**,本文档详细设计 |
| 后续篇章 | 更辽阔的天地:超级城市衡州、诸君主的领地、海 | 正阶及以上 | 仅保留大纲(第 17 节),以后再做 |

**当前只做第一篇。** 凡是只在后续篇章才用得到的内容(正阶以上的成长、多数进阶元素内容、其他君主),本文档只定规则,不排进里程碑。

## 2. 世界观

### 2.1 基本设定

- 这是一个科技水平相当于当代的世界,但文明的基础不是物理学而是**灵能**。列车、通讯、电网都由灵能驱动,学校里教灵术就像教数理化。
- 灵能弥漫于大地。长期浸染灵能的动物会异变为**异兽**,对人类聚居地有强烈攻击性。
- 人类生活在由**结界塔**环绕的城市与走廊中。结界外的土地统称**荒域**,约占陆地的三分之二。
- 异兽会不定期成规模地冲击结界,称为**兽潮**。

### 2.2 人与异兽的战力规则

灵能师的位阶与异兽的等级一一对应(见 3.1 与 4.1),但**同阶之下异兽远强于人**:

- 一只异兽,通常需要 **3–5 名同阶灵能师协力**才能击败。因此人类以猎队、守备队的形式集体作战,单打独斗被视为送死。
- 高一个大阶的异兽,对低阶灵能师而言基本不可力敌,只能依靠结界、城防和更高阶的灵能师。**每一个大阶的差距都是天差地别**,而且位阶越高,这道鸿沟越深。
- 一座城市的安危,取决于它最强的几名灵能师与它周边最强的异兽之间的差距。正阶与见习在一条街、一段城墙上能决定胜负,在整场战争的尺度上无足轻重。

**主角是例外。** 凭借天赋(3.7)与积累(3.8),主角可以单挑同阶异兽;积累深厚、手法高超时可以越一个小阶,极限情况下能与高一个大阶的对手周旋。越阶随位阶提高而越来越难。具体规则见 9.2。

### 2.3 君主

- 世上存在**多名君主级**异兽,各自盘踞一方(海、高山、荒漠、雪原……),是人类目前无法战胜的存在。人类的版图,实际上是君主们"没兴趣"的那部分土地。
- 人类的**宗师**极其稀少,几乎每一位都坐镇一座**超级城市**,牵制着与自己对应的那名君主,无法抽身。因此小城遇险时,超级城市能派出的援军只有少数几名灵能大师。
- 云溪所在的海域属于君主**潮主「无岸」**。它栖于外海深处,对小城与其周边的争斗**不屑出手**。
- 但它有一条人类用血换来的规律:**每当沿海有城市破灭(结界全部熄灭),无岸便会现身**,以威压震慑人类、勒令其离开,把那片土地划回自己的疆域。它不屠戮逃走的人,也不容许人留下。二十年前的临江就是这样变成沉城的。
- 其他君主留待后续篇章。

### 2.4 家园:云溪

- 一座河谷中的**边境小城**,人口约八万,三面环山,溪河穿城而过,向东数公里入海。天气好的时候,从东门城墙上能望见海和沉城的轮廓。
- 城市分四个区,每区有一座主结界塔:**东门区**(守备队驻地)、**河港区**(集市与猎人公会)、**学院区**(云溪学院与研究所)、**旧城区**(居民区,主角的家)。
- 云溪的结界塔已服役七十余年,近期开始出现不明原因的闪断。
- 离云溪最近的超级城市是**衡州**,经灵轨干线相连。云溪没有大学,学生高考后都要去往大城市。

**云溪的战力**(这决定了第一篇的力量天花板):

| 位阶 | 人数 | 说明 |
|---|---|---|
| 灵能大师 | 2 | 学院院长**顾松年**(年迈退休,灵核衰退,能动用的灵能已经不多);市长兼守备军统帅**岳峙**(壮年,云溪真正的最强战力) |
| 正阶灵能师 | 四十余 | 守备队队长、公会资深猎人、学院教师 |
| 见习灵能师 | 千余 | 守备队士兵、普通猎人、应届毕业生 |
| 其余觉醒者 | 约一万五千 | 觉醒后没有继续修炼,停留在见习下位,灵能只用于生活与工作 |
| 未觉醒者 | 六万余 | 启灵失败的大多数人 |

- 云溪周边荒域的异兽**最高为领主级,且仅有一只**(4.3)。按 2.2 的规则,击败一只领主需要数名灵能大师协力,而云溪只有两名,其中一名已近枯竭。单是这一只领主,就要两名灵能大师拼死才拖得住。**云溪守不住**,这是第一篇的既定结局。

### 2.5 历史:临江

二十年前,入海口的大城临江在一夜之间结界全灭,被兽潮吞没;随后无岸自海中现身,幸存者被逼离故土。临江如今称为**沉城**。官方结论是"设备老化"。幸存者散落在云溪各处,其中一些人知道的比官方说法更多。

### 2.6 核心秘密(主线揭示)

结界塔并非单纯的"盾"。它通过抽取周围土地的灵能来维持结界,塔越强,周边荒域越贫瘠,饥饿的异兽便被逼向城墙。**兽潮在一定程度上是结界自己造成的。** 临江的陷落,是当年一位结界工程师试图证明并修正这一点时出的事故。

云溪正在重演这个过程:结界塔越修越强,烬岭深处那只领主的领地越来越贫瘠。

### 2.7 教育与高考

| 年龄 | 阶段 | 内容 |
|---|---|---|
| 15–16 岁 | 高一 | 一年理论学习。学年末举行**启灵仪式**与理论结业考。**约八成的人启灵失败** |
| 16–18 岁 | 高二、高三 | 觉醒者升入灵能班,两年修炼灵能技:实训、狩猎、考核。未觉醒者转入普通科,学一门营生 |
| 18 岁 | **高考** | **文考**(理论)+ **武考**(实战),成绩决定去哪座城市的学府 |

- 云溪学院是云溪唯一的学校,设高中部与结界研究所。
- **天赋者一经显现就会被挖走。** 超级城市的招生官常年在各地的启灵仪式上守着,天赋者当场拿到预录取,前途无量。小城因此几乎留不住天赋者。

### 2.8 人类的叛徒:归潮

- **归潮**是一个信奉君主的秘密组织,认为沿海本就该还给海,人类的城市破灭得越早,死的人越少。
- 他们做两件事:破坏结界,以及**猎杀年轻的天赋者**(称为"拔苗")。启灵档案是他们最想要的东西。
- 因此天赋在这个世界上既是通行证,也是催命符。**显现天赋之后说还是不说**,是每个天赋者都要面对的抉择,也是主角的第一个重大抉择(见剧情大纲第 5 节)。
- 归潮与破壁会不是一回事。破壁会想修正结界以救人;归潮暗中资助并利用他们。

### 2.9 主角:来自平行时空的穿越者

- 主角来自一个**平行时空**:那里也有云溪,有同一个家、同一所学校、同一批人,只是没有灵能。主角在启灵前一个月醒来,成了这个世界的自己。
- 所以**这里的人和地方主角都认识**。母亲还是母亲,同桌还是同桌,家门口还是那条街。主角不必从头认识这座城。
- 但**处处有出入**。有些只是细节(面馆的灶台烧的是火系灵纹);有些是整个人生(这里的父亲不是死于车祸,而是在镜沼殉职);有些是整座城市(主角记忆里外婆家所在的临江,在这里是二十年前陷落的沉城)。
- **主角不懂的是这个世界的规则**:灵能、异兽、结界、位阶。序章既是剧情也是教程。
- **出入是线索,也是陷阱。** 两个世界不一样的地方,往往是这个世界出过事的地方。而主角对某些人"本能的信任"来自另一个世界,在这里未必成立。
- 游戏内以"两界札记"记录主角发现的每一处出入(见剧情大纲第 3 节)。
- 穿越是主角的又一个秘密。这个世界原来的那个"自己"去了哪里,穿越与主角的天赋、与终章无岸的那一瞥之间有什么关系,留待后续篇章。

## 3. 灵能体系

### 3.1 启灵与位阶

- 所有学生在 16 岁、高一学年末参加**启灵仪式**。**大部分人觉醒失败**;约两成的人觉醒一种元素,成为**灵能师**。游戏从启灵前一个月开始。
- 位阶分**大阶**与**小阶**。大阶四级,每个大阶内分**下位、中位、上位**三个小阶。

| 大阶 | 简称 | 常人可用元素数 |
|---|---|---|
| 见习灵能师 | 见习 | 1 |
| 正阶灵能师 | 正阶 | 2 |
| 灵能大师 | 大师 | 3 |
| 灵能宗师 | 宗师 | 4 |

- 宗师之上**可能还有一个大阶**,随后续篇章的剧情加入;届时常人可用的元素数相应增加。
- 元素共十二种(七种基础、五种进阶)。常人终其一生四种,「双生灵核」八种;极其罕见的奇遇「无相灵种」可以额外多觉醒一种(3.12)。所以理论上存在集齐全部元素的可能,实际上从未有人做到。
- **每提升一个小阶**:习得主修元素在这一小阶的一个灵能技(3.3);可自动运转上一小阶的吞吐量(3.9);上一小阶的灵能技变为一键释放(3.10)。
- **每突破一个大阶**:得到一次再觉醒一种元素的机会(天赋「双生灵核」为两次;觉醒不保证成功,见 3.2);上一大阶的全部灵能技威力大幅提升、消耗降低(3.3)。
- **突破**需要修为圆满,并完成一次"冲关"(一段更长的灵链)。大阶突破另需一次试炼。

**第一篇的成长范围:见习下位 → 见习上位。** 主角在云溪的两年里不会突破到正阶;正阶的突破是下一篇的开端。主角离开云溪时修到什么程度,取决于玩家这两年的努力。

### 3.2 元素

**基础元素**(启灵时可能觉醒的元素):

| 元素 | 战斗定位 | 世界用途 |
|---|---|---|
| 火 | 范围伤害、持续灼烧 | 点燃草木、照明、融冰 |
| 霜 | 减速、冻结控制 | 冻结水面成桥、熄火 |
| 雷 | 高速单体、导电连锁 | 为休眠的结界机关充能 |
| 风 | 击退、机动 | 上升气流、滑翔、远跳 |
| 岩 | 护盾、地形制造 | 升起石柱与掩体、堵路 |
| 水 | 施加湿润、推移、持续压制 | 灭火、引水、改变水道 |
| 木 | 缠缚、毒、持续恢复 | 催生藤桥与藤梯、催熟药材 |

**进阶元素**(常人到灵能大师才可能觉醒;天赋「异核」在启灵时觉醒的就是进阶元素):

| 元素 | 定位 |
|---|---|
| 光 | 治疗、净化、驱散黑暗与潜行异兽 |
| 影 | 潜行、暗杀、短暂隐身 |
| 契 | 召唤与驯服异兽协同作战 |
| 空 | 短距闪现、牵引、放置传送锚点 |
| 时 | 迟滞、加速、回溯。最罕见的元素 |

**元素的世俗评价。** 基础元素在世人眼中有高下之分,标准是正面杀伤力:

| 评价 | 元素 | 世人的看法 |
|---|---|---|
| 上品 | 雷、火 | 攻伐最强,名校与军方争抢 |
| 中品 | 霜、风、水 | 控制与辅助,中规中矩 |
| 下品 | 岩、木 | "修城墙的"和"种地的",被视为工科与农科 |

- 世俗评价影响分班、资源配给、武考的基准分以及旁人的态度,**不影响实际强度**:七种基础元素在玩家手中是平衡的。这个世界的主流战法是单元素齐射,对元素之间的配合研究很浅;主角带着另一个世界的思路,看得到别人看不到的用法。
- 觉醒上品元素更受重视,也更引人注目;觉醒下品元素无人问津,也无人打扰。主角觉醒哪一种是运气,但每一种运气都各有好处与麻烦。

**元素的觉醒。**

- **启灵时元素随机,不可选择。** 约八成的人什么也觉醒不了;觉醒者得到七种基础元素中的一种,上品更少见(初定:雷、火各 10%,霜、风、水各 15%,岩、木各 17.5%)。
- **主角必定觉醒**,但觉醒哪一种全凭运气,每个新存档重新决定。任何一种元素都能通关(见 [元素进阶与灵能技](ELEMENTS.md) 第 4 节)。
- 启灵失败的人日后可以花钱再试,但代价高昂、成功率更低,绝大多数家庭就此作罢。
- **此后的觉醒可以主动选方向,但不保证成功。** 每次大阶突破得到一次觉醒机会,有两种用法:

| 做法 | 花费 | 结果 |
|---|---|---|
| **引导觉醒** | 指定一种元素,投入该元素的灵晶与引灵的费用。投入越多、条件越好(高品级灵晶、对应属性的灵脉、同元素的高阶灵能师护法),成功率越高,但永远到不了十成 | 成功则觉醒所选的元素。**失败则什么也没有,投入全部耗尽**;想再试,就得再投一次 |
| **随机觉醒** | 最低的花费 | 必定觉醒,但元素随机(尚未拥有的基础元素之一;灵能大师以上才有极小的可能出现进阶元素) |

- 觉醒机会不会过期:可以先攒够资源再引导,可以失败后改走随机,也可以一直空着。
- 引导进阶元素的花费远高于基础元素,成功率也更低。
- 「双生灵核」每次有两次机会,各自结算、各自花费。
- 这是"元素越多,资源越多"的又一层:想要指定的元素,先得付得起失败。第一篇里主角用不到后续觉醒,但 NPC 的经历与下一篇的开局都以此为准。

主角在第一篇通常只有一种元素。元素之间的配合主要来自**小队成员**(8.5)和**环境**(3.5)。

### 3.3 元素进阶与灵能技

完整的进阶路线与技能表见 [元素进阶与灵能技](ELEMENTS.md)。

- **每种元素一条独立的进阶路线**,阶段与位阶的小阶一一对应(见习下位到宗师上位,共 12 个阶段)。
- 灵能师的位阶取其**主修元素**(进阶最高的那一种)的阶段。其余元素的阶段不能超过主修元素。
- **新觉醒的元素从见习下位练起**,要用该元素自己的灵晶另行修炼。**元素越多,需要的资源与时间越多。**
- **每修到一个阶段,习得该阶段的一个灵能技。** 技能是固定的,人人相同;只有奇遇才能带来变种(3.12)。
- **每突破一个大阶**,该元素上一大阶的三个灵能技威力大幅提升(初定 ×2)、灵能消耗减半。

见习的三个灵能技(第一篇主角能学到的全部):

| 元素 | 下位(基础攻击) | 中位(兼具探索用途) | 上位(范围或控制) |
|---|---|---|---|
| 火 | 火弹 | 引火 | 爆燃 |
| 霜 | 冰锥 | 凝冰 | 霜环 |
| 雷 | 电弧 | 充能 | 连锁闪电 |
| 风 | 风刃 | 乘风 | 气爆 |
| 岩 | 岩弹 | 升岩 | 岩壁 |
| 水 | 水箭 | 引流 | 涌浪 |
| 木 | 棘刺 | 催生 | 缠缚 |
| 光 | 光矢 | 愈光 | 耀斑 |
| 影 | 影刺 | 潜影 | 影缚 |
| 契 | 契印 | 唤兽 | 同调 |
| 空 | 裂隙 | 闪现 | 牵引 |
| 时 | 时蚀 | 回溯 | 缓域 |

正阶及以上的灵能技在第一篇中由 NPC 施展:正阶的老师与队长,以及两位灵能大师。

### 3.4 灵纹

- 灵纹是嵌入单个灵能技的小型改造件,调整它的细节(射程、范围、附带效果),不改变技能的本质。改变本质的是变种(3.12)。
- 每个灵能技 1 个灵纹槽,可随时在安全区更换。
- 灵纹由铭纹师刻制(8.7),或从遗迹、委托、巢主身上获得。

### 3.5 元素反应

**湿润**是许多反应的引子。它来自水系灵能技、雨天、水域与沼泽。

| 条件 | 结果 |
|---|---|
| 湿润 + 雷 | **传导**:伤害在湿润目标之间连锁 |
| 湿润 + 霜 | **冻结**:目标被定身 |
| 水 + 火 | **蒸汽**:产生遮蔽视线的雾 |
| 火 + 霜 | **消融**:解除冻结,目标变为湿润 |
| 火 + 风 | **火旋**:火焰范围扩大并蔓延 |
| 风 + 霜 | **暴雪**:大范围减速 |
| 风 + 水 | **骤雾**:大范围湿润并遮蔽视线 |
| 岩 + 火 | **熔岩**:岩造物变为持续灼烧的地面 |
| 岩 + 雷 | **崩碎**:岩造物炸裂成破片 |
| 岩 + 水 | **泥沼**:地面化为减速的泥潭 |
| 木 + 火 | **燎原**:木造物剧烈燃烧,范围与伤害大增 |
| 木 + 水 | **疯长**:木造物迅速生长,缠缚与恢复效果增强 |

环境同样参与反应:草地会烧、水面会冻、雨天强化雷与水而削弱火。反应可以由主角与队友的灵能技先后命中触发。进阶元素的反应留待后续篇章。

### 3.6 角色资源

| 资源 | 用途 | 恢复 |
|---|---|---|
| 生命 | 归零即倒下 | 食物、药剂、光元素、安全区 |
| 灵能 | 释放灵能技的消耗;链接失败同样消耗 | 随时间恢复,战斗外更快;吞吐可加速 |
| 体力 | 冲刺、闪避、游泳、滑翔 | 停止消耗后快速恢复 |

### 3.7 天赋

- **天赋**极其罕见:寻常天赋**万里挑一**,天赐天赋更是百万中无一。拥有天赋的人称为**天赋者**。主角必定是天赋者。
- 主角的天赋在启灵仪式上**随机抽取一个**,全凭运气,抽到后终身不变。每个新存档重新抽取。
- 所有天赋都只带来优势,没有负面效果。稀有度只影响抽中概率。
- 启灵石只测得出元素,测不出天赋。天赋显现时只有本人知道,**是否上报由本人决定**(2.8)。
- **NPC 也可以是天赋者**,与主角共用同一张表。但天赋者一经显现就被超级城市带走,留在云溪的只有隐瞒者与漏网者,寥寥数人,极难结识(8.5)。

| 天赋 | 稀有度 | 效果 |
|---|---|---|
| 双生灵核 | 天赐 | 启灵时随机觉醒**两种**不同的元素(第一篇即拥有 2 种);此后每次大阶突破有两次觉醒机会 |
| 异核 | 天赐 | 启灵时觉醒的是进阶元素(光、影、契、空、时中随机一种) |
| 潮汐灵脉 | 寻常 | 灵能上限 +50%,战斗中的灵能恢复不减速,吞吐效率提高 |
| 共鸣之体 | 寻常 | 元素反应的效果 +50%,持续时间延长 |
| 疾咏 | 寻常 | 灵链的链接速度大幅提高,灵能技冷却 −30% |
| 灵纹亲和 | 寻常 | 每个灵能技额外多一个灵纹槽 |
| 残火 | 寻常 | 受到致命伤时保留 1 点生命并短暂无敌,每 5 分钟一次 |
| 兽语 | 寻常 | 无需契元素即可驯服游荡级异兽,驯兽不占小队名额 |
| 界感 | 寻常 | 能看见灵能的流向:更容易找到灵脉与灵晶矿点,隐藏的遗迹、巢穴、异兽弱点会被标出 |

- **概率**:两个天赐天赋各 10%,七个寻常天赋平分其余 80%。*(数值待平衡)*
- **天赐天赋难养。** 这是它们的平衡所在:
  - 「双生灵核」的两条进阶路线各自要用各自的灵晶修炼,资源与时间都是双份。只养一条,另一条就是摆设。
  - 「异核」的进阶元素灵晶极其稀少,云溪的市面上根本没有,学院也不配给,只能进荒域找、靠奇遇得。
  - 天赐天赋给的是上限,不是起点。资源跟不上时,天赐天赋者的进境反而比常人慢。
- **剧情联动**:NPC 会对主角的天赋作出反应。破壁会首领渡者本人是「界感」天赋者,他正是因此看见了结界塔抽取土地灵能的事实;主角若同为「界感」,第四章会多出专属对话与线索。

### 3.8 积累

"积累"是同一小阶内的纵向成长,是主角能越阶挑战的另一半原因。常人缺少灵晶、时间与天赋,积累有限;主角可以把它堆得很深。

| 积累 | 来源 | 作用 |
|---|---|---|
| 修为 | 吞吐修炼(3.9) | 填满即可冲关;修为越深,灵能技威力越高 |
| 熟练度 | 反复练习与实战中链接灵链(3.10) | 链接更快、更稳,每个灵能技独立计算 |
| 淬炼 | 消耗灵晶 | 永久提升灵能上限与恢复速度;每个小阶有上限 |
| 灵纹与灵具 | 制作、商店、掉落 | 调整灵能技细节;灵器、灵衣、护符三个部位,带词条 |
| 变种与灵种 | 奇遇(3.12) | 灵能技的另一种形态 |

一个小阶内修为、熟练度、淬炼全部堆满,称为该小阶**圆满**。

### 3.9 修炼:吞吐法

**没有一键修炼。** 修为要靠玩家亲手运转吞吐法,把灵能一口一口吸纳进灵核。

- **怎么练**:选择一种元素开始吞吐。玩家跟随灵能的涨落控制呼吸的节律:涨时吸,落时吐。节律踩得越准,这一轮吸纳的灵能越多;乱了节律会"岔气",损失这一轮的灵晶并受轻伤。不同元素的节律不同(火急、岩缓、风无定)。
- **用什么练**:吞吐消耗对应元素的**灵晶**(3.11)。不用灵晶只能吸纳周围环境里的灵能,在城里几乎没有收获。
- **在哪练**:

  | 地点 | 效率 | 风险 |
  |---|---|---|
  | 家中、学院静室 | 基础 | 无 |
  | 哨站 | 略高 | 偶有袭击 |
  | 荒域的灵脉 | 高出数倍,且部分灵脉自带元素属性 | 会被异兽打断;可能触发事件与奇遇 |

  城内的灵能被结界塔抽走了,所以稀薄;越往荒域深处越浓。**想练得快,就得去危险的地方练。**
- **时间**:一次吞吐约一两分钟现实时间,对应游戏内的几个小时。
- **自动吞吐**:修到下一个小阶之后,上一小阶的吞吐量变成本能,可以在休息、睡觉时**自动运转**。当前小阶更高的吞吐量仍须手动。因此见习下位没有任何自动修炼;到见习中位,才能自动运转下位的吞吐量。
- **冲关**:修为填满后可以冲关。冲关是一段比任何灵能技都长的灵链(3.10),失败会损失一部分修为并受反噬,需要休养。

### 3.10 灵链

释放灵能技的方式是在灵核中把若干**节点**按固定的走向连成一条**灵链**。每个灵能技有自己的链式。

**学会一个灵能技**:修到对应阶段只是有了资格。玩家要在练习中第一次完整地连出它的灵链,才算学会。

**释放当前阶段的灵能技**(必须当场链接):

1. 按住技能键,准星周围出现灵链盘,显示节点。
2. 用鼠标(或手柄右摇杆)按顺序划过各个节点。链接期间可以移动,但速度降低,不能闪避。
3. 连完后松开,灵能技朝准星方向释放。
4. **链接失败**(连错、超时、被打断):灵能技不释放,**灵能照常消耗**,并有短暂的反噬硬直。

**熟练度**:每个灵能技单独计算。平时练得越多、实战中连成功得越多,熟练度越高:

- 判定更宽,允许的时间更长。
- 链式开头的节点会自动接上,需要手动连的节点变少(至少保留两个)。
- 一个刚学会的见习灵能技要一秒多才连得出;练熟之后不到半秒。

**一键释放**:修到下一个小阶之后,上一小阶的灵能技变成本能,按键即出,不再需要链接。突破大阶时,上一大阶的全部灵能技都是一键释放,并且威力大增。

| 主角的阶段 | 一键释放 | 需要当场链接 |
|---|---|---|
| 见习下位 | — | 下位技 |
| 见习中位 | 下位技 | 中位技 |
| 见习上位 | 下位技、中位技 | 上位技 |

- 每种元素的进阶路线各自计算。新觉醒的元素要从头练起。
- 练习场所:学院训练场、家中、任何安全的地方。练习不消耗灵晶,只消耗时间与灵能。
- 这套规则对 NPC 同样成立:同阶的 NPC 用当前阶段的灵能技也会失手。队友的熟练度随好感度与同行次数提高。

### 3.11 灵晶

**灵晶**是凝固的灵能,修炼的根本资源。

- 按**元素**分十二种,只能用于对应元素的修炼。按**品级**分碎晶、整晶、纯晶。
- 用途:吞吐修炼(修为)、淬炼。阶段越高,需要的品级越高、数量越多。
- **元素越多,要养的路线越多,灵晶需求成倍增加。** 进阶元素的灵晶极其稀少。

| 来源 | 能得到什么 | 说明 |
|---|---|---|
| 学院配给 | 基础元素碎晶,按月 | 重点班与上报线才有 |
| 市面 | 基础元素碎晶,限量、价高;整晶偶尔有 | **纯晶与进阶元素灵晶没有卖的** |
| 炼化兽核 | 与异兽属性相同的灵晶 | 有损耗;猎得越多换得越多 |
| 探脉采掘 | 各品级、各元素,包括市面没有的 | 在荒域的灵脉与矿点,多有异兽盘踞(8.7 探脉师) |
| 委托、声望、事件 | 视情况 | — |
| 黑市 | 便宜的灵晶 | 来路不明,见剧情大纲 |
| 奇遇 | 纯晶、灵种 | 可遇不可求 |

城内不产灵晶。**主角想比别人走得快,就必须冒险出城去找。**

### 3.12 奇遇与灵种

- **奇遇**是小概率的特殊事件,带来寻常途径得不到的东西。它属于事件系统(8.6)的一类,多发生在荒域深处、巢穴、遗迹、灵脉,以及副职业的活动中(8.7)。
- 奇遇通常伴随风险:要战斗、要取舍、或者要付出代价。
- 第一篇的奇遇种类:

  | 奇遇 | 得到什么 |
  |---|---|
  | **元素灵种** | 提升该元素全部灵能技的威力,并使其全部获得变种。每种元素只能融合一枚 |
  | **无相灵种** | 极度稀有。获得一次额外的觉醒机会,突破元素数量的上限。第一篇至多一枚 |
  | 残篇、遗刻 | 单个灵能技的变种 |
  | 纯晶矿点 | 大量高品级灵晶 |
  | 前人遗物 | 灵具、灵纹、图谱 |
  | 异兽幼崽 | 可驯养的伙伴(需「兽语」或契元素) |
  | 灵脉秘地 | 一处效率极高、无人知晓的修炼地 |
  | 高人指点 | 某个灵能技的熟练度大幅提高,或学到副职业的独门手法 |

- 灵种与变种的完整列表见 [元素进阶与灵能技](ELEMENTS.md) 第 5 节。
- 奇遇的结果在触发时确定,不能靠读档刷。
- **奇遇所得可以自用,也可以送人。** 灵种、残篇、灵晶等都能赠予 NPC,对方得到同样的增幅(8.5)。

### 4.3 巢主、领主与君主

**巢主**是有名字的头领级异兽,各占一处巢穴。对见习的主角而言,讨伐巢主是越一个大阶的极限挑战:需要该小阶圆满、带满小队、做足准备并破解弱点,且队友有阵亡的风险。全部为可选内容。

| 巢主 | 所在 | 等级 | 特点 |
|---|---|---|---|
| 「断尾」 | 竹海 | 头领下位 | 灰牙犬群之首,不断召来犬群,自身极快 |
| 「沉灯」 | 镜沼 | 头领下位 | 巨型沼灯,让整片沼泽陷入黑暗,只剩它的诱光 |
| 「铁脊」 | 烬岭 | 头领中位 | 巨型甲背兽,冲锋会改变地形 |
| 「末班车」 | 沉城 | 头领上位 | 盘踞在一列废弃灵轨列车里的壳居者,可选的极限挑战 |

**领主「衔烛」**(领主中位):盘踞在烬岭深处火山口**烛渊**的巨型火蜥,云溪周边唯一的领主。它的领地被云溪的结界塔逐年抽干,正在一步步逼近云溪。主角在第一篇中**无法对它造成有效伤害**;它在第一篇中不会被击败。

**君主·潮主「无岸」**:见 2.3。第一篇中它只在终章现身,不可交战。

### 4.4 掉落

异兽掉落**兽核**(按等级分档,是制作的核心材料,也可炼化为同属性的灵晶)和各科专属材料。巢主首次击败必掉一枚稀有灵纹。

### 5.1 规模与结构

### 5.2 区域

| # | 区域 | 推荐位阶 | 特征 |
|---|---|---|---|
| 0 | 云溪与结界内农田 | 安全 | 主城枢纽:学院、公会、集市、住所 |

### 5.3 哨站与移动

- 地图上有 6 座**哨站**。修复哨站后成为快速旅行点、复活点和补给点。
- 城内与已修复哨站之间可通过**灵轨**快速旅行。灵轨的干线通往超级城市衡州,是云溪与外界唯一的陆路联系。

### 5.4 世界规则

- **昼夜**:一个游戏日约 40 分钟现实时间。夜间异兽更多更强,部分异兽和事件只在夜间出现。
- **天气**:晴、雨、雾、雷暴,影响元素反应和异兽行为。
- **倒下**:在最近的哨站或城内诊所醒来,身上未存放的兽核与灵晶掉落在倒下地点,可回去拾取一次。

### 8.4 沙盒活动

- **修炼**:吞吐、练习灵链、冲关。全部手动(3.9、3.10)。
- **寻找灵晶**:探脉、狩猎后炼化兽核、委托、黑市(3.11)。
- **副职业**:见 8.7。
- **委托**:公会板上程序生成的狩猎、采集、护送、清巢任务,无限供应。
- **家**:旧城区"晚来面馆"楼上,与母亲、妹妹同住。自己的房间可扩充储物与工作台;在面馆帮忙、陪伴家人是日常活动的一部分。

- **哨站经营**:修复并升级哨站(防御、补给、灵轨站),可派驻队员。
- **探索发现**:遗迹、临江旧档案、隐藏巢穴、灵脉、观景点。

### 8.5 小队与好感度

人类以猎队作战是这个世界的常态。

**编制**

- **由玩家决定**:猎队的规矩是满编出行,出城最多带 **3 名队友**(连主角共四人)。但主角可以只带一两人,或者独行。
- **取舍**:人多则稳,但兽核、灵晶等战利品按出战人数分配;独行所得全归自己,积累最快,也最危险。
- **多样性**:每名队员有自己的元素、位阶、战斗定位、性格。队友的元素与主角不同,是第一篇触发元素反应的主要方式。
- **指令**:集火、守位、跟随、自由行动四种简单指令;队友会主动配合主角打出反应。
- **队友会死。** 队友倒地后进入濒死状态,限时内救起则重伤、回城休养;救不起,或主角撤退时把他留下,即**永久阵亡**。越阶讨伐与高潮位区域风险最高。阵亡会被他的家人、同乡和其他队友记住。
- 未出战的队员可派驻哨站或城区,提高该处的防御评分。

**好感度**

每个有名有姓的 NPC 对主角都有好感度,不限于队友。

- 五个层级:**陌生 → 相识 → 信任 → 托付 → 生死**。
- **好感度因人而异。** 每个 NPC 有自己的性情(升得快或慢)、喜恶(看重什么、反感什么)和门槛(某些层级要先经历特定的事才能跨过)。老秦一碗面就记你的好;沈砚只认战功;渡者要的是你听他把话说完。
- **有人的好感几乎升不动。** 心里藏着事的人对谁都客气,对谁都不交底:好感涨得极慢,而且卡在某一层上不去。归潮的内应就是这样。**一个怎么也处不熟的人,本身就是线索。**
- 好感度的来源:并肩作战、救过他或他在乎的人、完成他的请求、事件中的选择、投其所好的赠礼。会掉:见死不救、背弃承诺、让他的同伴白白送命。
- 好感度的作用:

  | 层级 | 作用 |
  |---|---|
  | 相识 | 愿意交谈、交易、接受委托 |
  | 信任 | 愿意入队;说出自己的事;战斗中主动配合 |
  | 托付 | 服从危险的指令;把压箱底的东西教给主角(奇遇"高人指点");主角不在时会照看主角的家人 |
  | 生死 | 愿意为主角断后;终章会出现在主角最需要的地方 |

**赠予**

主角手里的资源与奇遇所得,可以自己用,也可以送给 NPC。

- 可赠予的东西:灵晶、药剂、灵具、灵纹、残篇、灵种,乃至无相灵种。
- **NPC 得到与主角相同的增幅。** 送灵晶,他的修为会涨、会提升小阶、学会新的灵能技;送灵种,他的灵能技也会有变种;送灵具,他会穿上。常人缺的就是资源,所以主角的一份馈赠可能抵得上他几年的苦修。
- **不会白费**:受赠的 NPC 入队后把这些实力用在主角身边;没入队的,会用在他自己的岗位上(守城墙的沈砚、撑着结界的顾松年)。两场围城战与终章的结算都按他们当时的实力算。
- **但有风险**:他若阵亡,投入就没了。他若另有立场,主角是在资敌。
- 赠礼也会提升好感度,幅度取决于对方的喜恶。有人收了重礼反而起疑。

### 8.6 事件与世界线

- 自由探索时会触发**事件**,要求玩家当场做出选择。事件分三类:**必出**(主线固定)、**条件**(满足条件即发生)、**概率**(按区域、时间与世界线状态随机)。
- 一个事件包含:触发条件、情境、2–4 个选项、即时结果、世界线标记。部分选项只在拥有特定元素、天赋、队友或声望时出现。
- 选择可能意味着战斗、危险、奖励或牺牲。后果不一定当场显现,可能在几章之后才到来。
- 概率事件一旦触发,其内容在该存档中即已确定,不能靠读档刷结果。
- **世界线变量**:暴露度、疏散准备度、城防、归潮渗透、每个人物的状态、主角的立场。定义与事件示例见剧情大纲第 11 节。

### 8.7 副职业

副职业让角色在修炼与狩猎之外多一条获取资源的路。每一门都要投入**时间**,都有**风险**,也都有自己的**奇遇**。

| 副职业 | 做什么 | 收益 | 风险 | 奇遇 | 入门 |
|---|---|---|---|---|---|
| 猎兽师 | 接公会悬赏,追踪并猎杀指定的异兽 | 悬赏金、兽核、异兽材料 | 悬赏目标常比自己高一个小阶;伤亡 | 变异个体、巢穴深处的灵种 | 公会执照,老秦带入门 |
| 探脉师 | 在荒域寻找灵脉与灵晶矿点并采掘 | **灵晶,包括市面上没有的品类** | 好矿都在深处,多有异兽盘踞;塌方 | 纯晶矿点、古矿道、灵脉秘地 | 公会,白鹭引荐 |
| 铸器师 | 锻造灵具与各种灵能道具 | 自用装备;出售换灵币 | 炸炉:损失材料并受伤 | 残缺的图谱、异材 | 河港区的铸器铺 |
| 铭纹师 | 刻制灵纹 | 自用;出售换灵币 | 反噬:一段时间内灵能上限降低 | 古纹拓片、遗刻 | 学院选修课 |
| 炼药师 | 采集药材并炼制药剂(疗伤、辅助吞吐) | 自用;出售换灵币 | 试药中毒;药材长在荒域 | 异草、古方 | 旧城区的药铺 |
| 结界匠 | 检修结界塔与哨站的灵纹线路 | 守备队的薪酬;进出结界塔的权限 | 离真相太近的人容易出事 | 塔基里的旧物、临江的旧图纸 | 祁闻或守备队 |

- **规则**:第一篇最多同时修**两门**副职业。每门分学徒、熟手、匠师三级,靠实际去做来提升。
- **同样没有一键**:锻造、刻纹、炼药都是手上的功夫,操作方式与灵链相近(刻纹本身就是在器物上连灵链);猎兽与探脉则是实打实地出城。
- **时间**:制作类的活动消耗游戏内的时间(半天到数天),外出类的活动占用一次出城。
- **与主线的关系**:副职业不是必需的,但几乎每一门都能在主线里派上用场。结界匠会更早接触到结界塔的异常;探脉师更容易发现烬岭灵能的逐年衰减;猎兽师的名声决定公会猎人在终章是否听主角的。
- 「兽语」天赋者与契元素的驯兽属于天赋与元素能力,不算副职业。

| 资源 | 用途 | 主要来源 |
|---|---|---|
| 灵币 | 日常货币:商店、家用、哨站与城防建设 | 委托、悬赏、出售制品与材料、面馆帮工 |

## 9. 战斗设计

### 9.1 基本操作

- **视角与瞄准**:第三人称越肩视角,准星自由瞄准,带轻度辅助瞄准。*(默认方案,待确认)*
- **释放灵能技**:已经越过的阶段的灵能技一键释放;**当前阶段的灵能技要当场链接灵链**(3.10)。链接时移动变慢、不能闪避,失败照样扣灵能。什么时候敢停下来连那条链,是战斗的核心判断。
- **节奏**:中等速度,强调走位、破解弱点、为链接争取时间、与队友打出元素反应,而非连招。
- **闪避**:消耗体力的翻滚,带短暂无敌帧。链接中不能闪避。
- **手法**:同样的位阶与积累,链接又快又稳的玩家强得多。这是"手法高超可以越阶"的含义。
- **敌人设计原则**:每种异兽至少有一个可以用元素或地形"破解"的行为(见 4.2 的弱点列),而不是只靠堆血量。破解弱点是越阶挑战的关键。

### 9.2 阶差与越阶

**阶差**指双方相差的小阶数(一个大阶 = 三个小阶)。阶位高的一方获得伤害与韧性上的压制,阶差越大压制越强。

| 对手 | 普通灵能师(无天赋、积累浅) | 主角 |
|---|---|---|
| 同阶同位 | 需 3–5 人协力 | 可以单挑,常规难度 |
| 高一个小阶 | 需一支满编猎队 | 积累充足即可单挑,困难 |
| 高一个大阶 | 需要更高阶的灵能师带队 | 该小阶圆满、手法高超时可以**周旋、拖住**,难以击杀;带满小队、做足准备并破解弱点才有击杀的可能,且队友有阵亡风险 |
| 高两个大阶及以上 | 不可力敌 | 不可力敌,只能在集体作战中承担任务 |

- **越阶随位阶提高而越来越难。** 见习对头领级的差距已是极限;正阶对领主级、灵能大师对君主级的差距逐级拉大,到后来不再是技巧可以弥补的。
- 主角没有隐藏的数值加成。主角强于常人的部分**全部来自游戏内可见的系统**:天赋、积累、小队,以及玩家自己的操作。
- 普通 NPC 灵能师按"无天赋、积累浅"设定数值,这样"常人需数人协力"与"主角可以单挑"用的是同一套规则。
- 阶差压制的具体数值在里程碑 1 的战斗原型中调试,目标是让上表每一行的体感成立。

## 10. 兽潮与城防

### 10.1 潮位

每个区域有 0–100 的潮位,显示在地图上,表示该区域异兽的密度与强度。潮位由主线章节设定下限,玩家清巢、修哨站可以压低它。

### 10.2 平时的软压力

- 被忽视的哨站会偶尔遭到袭击并降级(失去补给或灵轨功能),**不会永久丢失**,修复即可恢复。派驻队员可以降低被袭击的概率。
- 袭击只在玩家处于城外活动时判定,不会在玩家离线或做长对话时发生。

### 10.3 围城战的触发

围城战由主线任务节点触发:玩家完成章节的前置任务后,在城内主动确认"准备就绪"才开始。*(默认方案,待确认)* 确认前可以无限期自由探索。唯一的例外是终章"灭城之夜":一夜分六个时段,真实计时。

### 10.4 围城战的通用流程

1. **备战**:为四座结界塔投入材料加固,布置岩壁与陷阱,通过声望调配援军,安排未出战的队员驻守。每个城区得到一个"防御评分"。
2. **战斗**:数波异兽同时进攻四个城区。主角可带小队在城区间移动,自己选择守哪里;不在场的城区按防御评分与敌方强度自动推进。
3. **结算**:结界塔被摧毁的城区判定为失守。

### 10.5 两场围城战

| | 第三章:初潮 | 终章:大潮 |
|---|---|---|
| 起因 | 归潮内应瘫痪两座结界塔 | 领主衔烛出渊 |
| 敌方 | 数只头领级带领的兽群 | 衔烛、数十只头领级与全部兽潮 |
| 人类一方 | 岳峙与正阶们对付头领,见习守街巷 | 两名灵能大师拼死拖住衔烛;全城死守、疏散平民、等待衡州的三名灵能大师 |
| 目标 | 守住四座结界塔 | 没有胜利条件。尽可能多的人上车 |
| 主角的作用 | 带小队守一个城区。**这一仗主角的努力能保住城区** | 清理游荡级、拖住头领级、在各告急点之间取舍。影响的是谁活下来,不是战局 |
| 结果 | 城区的存续与损伤 | 第一篇的结算 |

### 10.6 失守的后果

- 初潮中失守城区的商店与设施关闭,相关 NPC 受伤暂离,该区潮位下限抬高。
- 损伤是持续的,但可以投入材料与灵币重建。重建程度影响大潮时该城区的防御评分。
- 大潮之后没有重建。结果直接写入第一篇的结算。

## 11. 界面

- **HUD**:生命/灵能/体力条、灵能技栏、队友状态、小地图罗盘、任务追踪。保持简洁,可在设置中逐项关闭。
- **灵链盘**:链接时出现在准星周围,显示节点、走向与剩余时间。熟练度高的节点自动点亮。
- **吞吐界面**:灵能的涨落曲线、呼吸节律、本轮吸纳量、修为进度。
- **菜单**:地图(潮位、哨站、灵脉、标记)、背包、灵能技与灵纹、修炼(修为、熟练度、淬炼)、副职业、小队、任务、图鉴(异兽、元素反应)、势力声望、设置。
- **图鉴**随遭遇与发现逐步解锁,是玩家了解弱点与反应的主要途径,也是高考文考的题库。

## 12. 本地化

- 支持**简体中文**与**English**,首次启动时选择,之后可在设置中随时切换,无需重启。
- **中文是源语言**:剧情、世界观、人物对白、图鉴文本一律先用中文创作,英文版是对中文的翻译。两者有出入时以中文为准。
- 代码与场景中不写死任何面向玩家的文本,全部通过翻译键读取。翻译表使用 CSV,一列一种语言,便于后续增加语言。
- 人名、地名采用"中文名 + 拼音"对应(云溪 / Yunxi);术语采用意译(结界塔 / Ward Tower)。
- 内置支持中文字符的开源字体(Noto Sans SC,OFL 协议)。
- 界面布局需同时容纳两种语言的文本长度。
- 暂不做配音,对话为文本。

## 13. 技术方案

| 项目 | 方案 |
|---|---|
| 引擎 | Godot 4 最新稳定版,开工时锁定具体版本号并写入本文档 |

| **不使用运行时 AI** | 游戏运行时不调用任何 AI 接口,可完全离线。玩家的自主性来自系统与状态:世界线变量、数据化的事件、按规则结算的后果、元素与环境的系统性互动。事件、对白与双语文本全部在开发阶段写成数据随游戏发布 |

### 开发方式

场景与脚本全部以文本形式编写并纳入版本管理,不依赖在编辑器里手工摆放。画面和手感的验收需要在本地运行 Godot 实机试玩。

## 14. 美术与音频

- **美术**:风格化低多边形。地形、建筑、植被以程序生成和基础几何体为主,可按需引入 CC0 协议的免费模型包。*(默认方案,待确认)*

- **城市观感**:现代东亚小城(公寓楼、骑楼、电线杆、便利店)叠加灵能设施(结界塔、灵轨、发光的灵纹路灯)。
- **尺度感**:领主与君主必须在体量上让人一眼明白"打不过"。无岸现身是全篇的视觉高潮。
- **音频**:首版使用 CC0 音效与环境音;音乐后置。
