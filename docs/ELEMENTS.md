# 元素进阶与灵能技

> 状态:**v0.1 草案**。规则见 [设计文档](DESIGN.md) 第 3 节;本文是各元素的进阶路线、灵能技表与灵种表。
> 数值均为初定,在战斗原型中调试。

---

## 1. 进阶路线的规则

- 每种元素一条独立的进阶路线,共 12 个阶段:见习、正阶、大师、宗师四个大阶,各分下位、中位、上位。
- **每修到一个阶段,习得该阶段的一个灵能技。** 技能是固定的,人人相同;只有奇遇才能带来变种(第 5 节)。
- **每突破一个大阶**,该元素上一大阶的三个灵能技威力大幅提升(初定 ×2)、灵能消耗减半。
- **当前阶段的灵能技必须当场链接灵链才能释放;已经越过的阶段的灵能技可以一键释放。**

### 技能的定位

每个大阶的三个技能遵循同一个设计规律,便于玩家预期:

| 小阶 | 定位 |
|---|---|
| 下位 | 该大阶的基础攻击手段 |
| 中位 | 兼具战斗与探索用途的功能技 |
| 上位 | 范围、控制或爆发,该大阶的代表技 |

### 灵链的节点数

| 大阶 | 下位 | 中位 | 上位 |
|---|---|---|---|
| 见习 | 3 | 4 | 5 |
| 正阶 | 5 | 6 | 7 |
| 大师 | 7 | 8 | 9 |
| 宗师 | 9 | 10 | 12 |

每个灵能技有自己固定的链式(节点的走向)。同一元素的链式有家族相似性:火系多折返,霜系多对称,雷系多锐角,风系多弧线,岩系多直线。熟悉一种元素后,学它的新技能会更快上手。

## 2. 基础元素

第一篇中主角只会用到见习的三个技能。正阶及以上的技能在第一篇里由 NPC 施展(正阶的老师与队长、两位灵能大师),并为后续篇章定下方向。

### 2.1 火

世俗评价:上品。定位:范围伤害、持续灼烧。

| 阶段 | 灵能技 | 效果 |
|---|---|---|
| 见习下位 | 火弹 | 单体火球,可蓄力。命中附加灼烧 |
| 见习中位 | 引火 | 点燃草木与可燃物、照明、融冰;对敌人附加灼烧并延长已有灼烧 |
| 见习上位 | 爆燃 | 指定地点的范围爆炸,引爆范围内的灼烧效果 |
| 正阶下位 | 炎墙 | 一道持续燃烧的火墙,阻断通路 |
| 正阶中位 | 炎步 | 短距突进,身后留下一条火径 |
| 正阶上位 | 坠火 | 抛射后从高处落下的巨大火球,大范围 |
| 大师下位 | 炎甲 | 火焰护身,灼伤近身者,免疫冻结 |
| 大师中位 | 焚野 | 把大片地面化为火场,持续很久 |
| 大师上位 | 陨焰 | 召来天火轰击一片区域 |
| 宗师下位 | 炎灵 | 召出自主作战的火灵 |
| 宗师中位 | 白炽 | 极高温的光束,熔穿岩石与甲壳 |
| 宗师上位 | 烬日 | 一轮小日悬于战场上空,领域内万物燃烧 |

## 3. 进阶元素

常人到灵能大师才能觉醒进阶元素;天赋「异核」可以在启灵时觉醒。进阶元素的灵晶极其稀少,云溪的市面上没有出售。

下表是第一篇需要的见习三技。正阶及以上留待后续篇章。

| 元素 | 见习下位 | 见习中位 | 见习上位 |
|---|---|---|---|
| 光 | **光矢**:光束攻击,对潜行与暗处的敌人加伤 | **愈光**:治疗一名目标并净化异常状态 | **耀斑**:范围致盲,驱散黑暗,逼出潜行者 |
| 影 | **影刺**:从目标的影子里刺出,背后命中加伤 | **潜影**:遁入阴影短暂隐身并移动 | **影缚**:用影子束缚范围内的敌人 |
| 契 | **契印**:标记目标使队友与契约兽集火;对虚弱的游荡级可尝试驯服 | **唤兽**:召出已缔约的异兽协同作战 | **同调**:与契约兽共享感知并强化它 |
| 空 | **裂隙**:在目标处撕开一道短暂的空间裂口 | **闪现**:短距瞬移 | **牵引**:把目标或物体拉近、推远 |

## 4. 见习技能的环境用途

第一篇的探索与解谜围绕各元素的见习中位技设计。任何一种元素都能通关,但走的路不同。

| 元素 | 中位技 | 探索中能做什么 |
|---|---|---|
| 火 | 引火 | 烧开藤蔓与蛛网、点亮黑暗的遗迹、融开冰封的通路、用烟驱赶巢中的异兽 |
| 霜 | 凝冰 | 在镜沼与溪河上冻出冰桥、封住漏水或喷火的管道、让湿滑的斜坡可以滑行 |
| 雷 | 充能 | 启动沉城的旧设备(升降机、闸门、灵轨道岔)、给哨站中继塔应急供能 |
| 风 | 乘风 | 越过断崖与城墙、从高处滑翔侦察、吹散毒雾与蒸汽 |
| 岩 | 升岩 | 垫脚上高处、堵住洞口与水流、在矿道里撑住塌方 |
| 光 | 愈光 | 救治倒地的队友与路上的伤者(更多可救的人) |
| 影 | 潜影 | 潜过头领级的巡逻范围、进入有人看守的地方 |
| 契 | 唤兽 | 让契约兽探路、搬运、引开敌人 |
| 空 | 闪现 | 穿过栅栏与裂缝、够到够不着的地方 |

## 5. 变种与灵种

### 5.1 变种

变种是灵能技的另一种形态。变种只能通过**奇遇**获得,概率很小,且不可逆。

| 来源 | 作用范围 |
|---|---|
| **灵种** | 一种元素的全部灵能技,包括日后习得的 |
| **残篇、遗刻** | 单个灵能技 |

### 5.2 灵种

灵种是天然凝成的元素之种,极其罕见。融合后:

- 该元素全部灵能技**威力提升**(初定 +20%)。
- 该元素已有的和日后习得的灵能技全部获得对应的**变种**。
- 每种元素只能融合一枚灵种,融合后不可更换。
- 融合灵种需要一次高难度的灵链链接;失败不会损毁灵种,但会受反噬。

灵种没有人会卖。它们在荒域深处、巢主的巢穴、沉城的废墟里,而且通常不是无主的。第一篇里能得到一枚已是极大的运气。

| 元素 | 灵种 | 变种效果 |
|---|---|---|
| 火 | 青焰 | 火焰变为青色,温度更高:无视部分护甲,可熔毁冰与岩的造物 |
| 火 | 余烬 | 火技结束后留下余烬,可被再次引爆 |
| 霜 | 玄冰 | 冰造物更坚固,冻结时间延长 |
| 霜 | 雾凇 | 霜技伴随浓雾,遮蔽视线并使范围内目标湿润 |
| 雷 | 紫电 | 连锁次数增加,对麻痹目标加伤 |
| 雷 | 静雷 | 雷技留下延迟引爆的雷印,可预先布置 |
| 风 | 罡风 | 风技附带切割,破甲 |
| 风 | 流岚 | 每次释放风技后获得一次短距位移 |
| 岩 | 玄铁 | 岩造物金属化:更硬、可导电 |
| 岩 | 流沙 | 岩技使周围地面沙化,减速并可吞没小型目标 |

进阶元素的灵种留待后续篇章。

### 5.3 单技变种的例子

| 灵能技 | 变种 | 效果 |
|---|---|---|
| 火弹 | 连珠 | 一次链接连发三枚小火弹 |
| 凝冰 | 冰镜面 | 冻出的冰面会反射雷系灵能技 |
| 连锁闪电 | 回环 | 最后一跳回到第一个目标 |
| 乘风 | 携行 | 可以带一名队友一起升空 |
| 岩壁 | 拱桥 | 岩壁横向生成,可作桥 |
