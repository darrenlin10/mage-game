# 元素进阶与灵能技

> 状态:**v0.6 草案**。规则见 [设计文档](DESIGN.md) 第 3 节;本文是各元素的进阶路线、灵能技表与灵种表。
> 数值均为初定,在战斗原型中调试。

---

## 1. 进阶路线的规则

- 每种元素一条独立的进阶路线,共 12 个阶段:见习、正阶、大师、宗师四个大阶,各分下位、中位、上位。
- **每修到一个阶段,习得该阶段的一个灵能技。** 技能是固定的,人人相同;只有奇遇才能带来变种(第 5 节)。
- **每突破一个大阶**,该元素上一大阶的三个灵能技威力大幅提升(初定 ×2)、灵能消耗减半。
- **当前阶段的灵能技必须当场链接灵链才能释放;已经越过的阶段的灵能技可以一键释放。**

### 命名

- 每个灵能技有一个正式的名字,多取自典故(扶摇、履霜、列缺、缩地、广陵)。宗师下位的"唤灵"技以司掌该元素的神祇为名(祝融、玄冥、飞廉、后土)。
- **融合灵种之后,灵能技的名字前面会加上灵种的名字作为前缀。** 例:火系的「赤星」在融合青焰灵种后称「青焰·赤星」,融合地火灵种后称「地火·赤星」;霜系的「履霜」融合玄冰灵种后称「玄冰·履霜」。
- 由残篇得来的单技变种,名字写在技能名之后。例:「赤星·连珠」。两者可以并存:「青焰·赤星·连珠」。

### 技能的定位

每个大阶的三个技能遵循同一个设计规律,便于玩家预期:

| 小阶 | 定位 |
|---|---|
| 下位 | 该大阶的基础攻击手段 |
| 中位 | 兼具战斗与探索用途的功能技 |
| 上位 | 范围、控制或爆发,该大阶的代表技 |

### 灵链的节点数

| 大阶 | 下位 | 中位 | 上位 |
|---|---|---|---|
| 见习 | 3 | 4 | 5 |
| 正阶 | 5 | 6 | 7 |
| 大师 | 7 | 8 | 9 |
| 宗师 | 9 | 10 | 12 |

每个灵能技有自己固定的链式(节点的走向)。同一元素的链式有家族相似性:火系多折返,霜系多对称,雷系多锐角,风系多弧线,岩系多直线,水系多回环,木系多分叉,金系多折线。熟悉一种元素后,学它的新技能会更快上手。

## 2. 基础元素

第一篇中主角只会用到见习的三个技能。正阶及以上的技能在第一篇里由 NPC 施展(正阶的老师与队长、两位灵能大师),并为后续篇章定下方向。

| 正阶下位 | 炎垣 | 一道持续燃烧的火墙,阻断通路 |
| 正阶中位 | 踏烬 | 短距突进,身后留下一条火径 |
| 正阶上位 | 堕阳 | 抛射后从高处落下的巨大火球,大范围 |
| 大师下位 | 曜甲 | 火焰护身,灼伤近身者,免疫冻结 |

| 大师上位 | 荧惑 | 召来天火轰击一片区域 |

## 3. 进阶元素

常人到灵能大师才可能觉醒进阶元素;天赋「异核」在启灵时觉醒的就是进阶元素。进阶元素同样从见习下位练起,路线同样是 12 个阶段。进阶元素的灵晶极其稀少,云溪的市面上没有出售。

第一篇只会用到见习的三个技能(「异核」的主角,以及影系的杜若)。

定位:治疗、净化、克制黑暗与潜行。

| 阶段 | 灵能技 | 效果 |
|---|---|---|
| 见习下位 | 流明 | 光束攻击,可蓄力。对潜行与暗处的敌人加伤 |
| 见习中位 | 春晖 | 治疗一名目标并净化异常状态;可救治路上的伤者 |
| 见习上位 | 破晓 | 范围致盲,驱散黑暗,逼出潜行者 |
| 正阶下位 | 明光 | 给自己或队友一层光幕,抵挡一次重击 |
| 正阶中位 | 清辉 | 一片驱散黑暗、解除异常、使潜行者显形的区域 |
| 正阶上位 | 烛照 | 持续照射的光柱 |
| 大师下位 | 返照 | 救起濒死的队友 |
| 大师中位 | 借昼 | 把夜晚的一片区域变成白昼,夜行异兽被削弱 |
| 大师上位 | 倾曜 | 自天而降的大范围光之轰击 |
| 宗师下位 | 羲和 | 召出自主作战的光灵 |
| 宗师中位 | 普照 | 大范围持续治疗 |
| 宗师上位 | 永昼 | 没有阴影的领域 |

| 见习下位 | 裂帛 | 一道音波冲击,可蓄力。穿透掩体,打断正在蓄力或链接灵链的目标 |
| 见习中位 | 空谷 | 回声定位:显示周围的敌人、空洞与隐藏的通道;也可以在远处制造声响引开异兽 |
| 见习上位 | 穿云 | 范围尖啸,眩晕并打断范围内的全部敌人 |
| 正阶下位 | 破阵 | 持续吟唱,范围内的队友威力与恢复提高 |
| 正阶中位 | 希声 | 一片没有声音的区域:脚步无声,异兽的嚎叫与召集失效 |
| 正阶上位 | 同声 | 锁住目标的固有频率持续震荡,伤害不断递增;对甲壳与岩、金、冰的造物尤其有效 |
| 大师下位 | 谛听 | 听见极远处与墙后的一切动静 |
| 大师中位 | 清商 | 使范围内的异兽平静下来,停止攻击 |
| 大师上位 | 广陵 | 大范围的毁灭性音爆 |
| 宗师下位 | 伶伦 | 召出自主作战的音灵 |
| 宗师中位 | 敕令 | 说出的一个字成为不可违抗的命令(止、退、碎) |
| 宗师上位 | 万籁 | 一切声音皆为施术者所用的领域 |

### 3.6 时

定位:**万能辅助**。加速、迟滞、回溯、重演,能让任何一支队伍、任何一种元素变得更强,自身几乎没有杀伤手段。**上限极高,是完美的辅助。**

时是最罕见、也最超出常规的元素,有专门的限制:

- **主角启灵时不会觉醒时**,包括天赋「异核」。只有辅助技的元素不适合作为唯一的起点。
- **NPC 启灵时觉醒时的概率微乎其微。** 有记载以来屈指可数,云溪无人拥有。
- 主角可以**引导觉醒**时,但有门槛。随机觉醒不会出现时。

  | 主角的位阶 | 能否尝试 | 后果 |
  |---|---|---|
  | 见习 | 不能 | — |
  | 正阶 | 可以,成功率极低极低 | **即使成功也等于绝路**:消息必然走漏,此后无时无刻不遭遇暗杀,一波强过一波,以正阶的实力完全抵挡不住。游戏会在尝试前明确警告,并建议到灵能大师再试 |
  | 灵能大师及以上 | 可以,成功率仍然很低 | 有了自保之力与靠得住的靠山,暗杀仍会来,但挡得住。这是建议的时机 |

- **为什么养不起**:时系前期的修炼耗费极大,所需的时系灵晶本身近乎传说。以主角出身小城的家底,前期根本不可能养成。
- **为什么会被杀**:时系的上限极高,是完美的辅助,一个养成的时系灵能师能让整支队伍、整座城的战力上一个台阶。所以每一方势力都想要,得不到的宁可他死。归潮尤其如此。
- **价值**:一旦在大师之后养成,时是全游戏价值最高的元素。
- 第一篇中,时只存在于传闻里。

| 阶段 | 灵能技 | 效果 |
|---|---|---|
| 见习下位 | 白驹 | 加快自己或一名队友的动作与灵链链接速度 |
| 见习中位 | 溯洄 | 让自己或一名队友回到三秒前的位置与状态;可复原刚刚损坏的小物件 |
| 见习上位 | 迟日 | 一片时间流速变慢的区域,敌人与弹道在其中变慢 |
| 正阶下位 | 继晷 | 延长范围内友方增益与造物的持续时间,并加快冷却 |
| 正阶中位 | 观往 | 短暂看见敌人接下来的动作并让队友也看见;在探索中看见一处地点不久前发生过的事 |
| 正阶上位 | 驻景 | 把单个目标定在时间之中片刻 |

## 5. 变种与灵种

### 5.1 变种

变种是灵能技的另一种形态。变种只能通过**奇遇**获得,概率很小,且不可逆。

| 来源 | 作用范围 |
|---|---|
| **灵种** | 一种元素的全部灵能技,包括日后习得的 |
| **残篇、遗刻** | 单个灵能技 |

### 5.2 灵种

灵种是天然凝成的元素之种,极其罕见。融合后:

- 该元素的灵能技**威力提升**。
- 该元素的灵能技获得对应的**变种**。
- 每种元素同时只能融合一枚灵种。日后得到更高品阶的,可以吞并旧的。

灵种分四个**品阶**,决定增幅的大小与变种能覆盖到哪一个大阶的灵能技:

| 品阶 | 威力提升(初定) | 变种覆盖 | 通常在哪里 |
|---|---|---|---|
| 低阶 | +10% | 见习的灵能技 | 巢主的巢穴、偏远的灵脉 |
| 中阶 | +20% | 见习与正阶的灵能技 | 领主的巢穴 |
| 高阶 | +35% | 至大师的灵能技 | 强大领主的秘境 |
| 绝品 | +50% | 全部灵能技 | 君主的疆域 |

同一种灵种(如青焰)可以有不同的品阶。第一篇能见到的只有低阶与中阶。
- 融合灵种需要一次高难度的灵链链接;失败不会损毁灵种,但会受反噬。

灵种没有人会卖。它们在荒域深处、巢主的巢穴、沉城的废墟里,而且通常不是无主的。第一篇里能得到一枚已是极大的运气。

| 元素 | 灵种 | 变种效果 |
|---|---|---|
| 火 | 青焰 | 火焰变为青色,温度更高:无视部分护甲,可熔毁冰与岩的造物 |
| 火 | 余烬 | 火技结束后留下余烬,可被再次引爆 |
| 火 | 地火 | 火技的落点留下一小片熔岩,持续灼烧,不易被水熄灭。**衔烛旧巢里的那一枚是中阶** |
| 霜 | 玄冰 | 冰造物更坚固,冻结时间延长 |
| 霜 | 雾凇 | 霜技伴随浓雾,遮蔽视线并使范围内目标湿润 |
| 雷 | 紫电 | 连锁次数增加,对麻痹目标加伤 |
| 雷 | 静雷 | 雷技留下延迟引爆的雷痕,可预先布置 |
| 风 | 罡风 | 风技附带切割,破甲 |
| 风 | 流岚 | 每次释放风技后获得一次短距位移 |
| 岩 | 磐岩 | 岩造物更坚固,并反震近身的攻击 |
| 岩 | 流沙 | 岩技使周围地面沙化,减速并可吞没小型目标 |
| 水 | 重水 | 水更沉重:推移与破坏力大增 |
| 水 | 甘霖 | 水技对友方附带少量治疗 |
| 木 | 铁木 | 木造物坚硬如铁,不易燃 |
| 木 | 毒瘴 | 木技的毒更烈,并会在敌人之间传染 |
| 金 | 流金 | 金属呈液态:可随意变形,命中后附着在目标身上持续切割 |
| 金 | 陨铁 | 金属更重:击退与破甲大增 |
| 光 | 曦 | 光技附带灼烧 |
| 影 | 墨 | 影技结束后留下一片持续的暗域 |
| 契 | 血契 | 契约兽大幅增强,但与主人分担伤害 |
| 空 | 镜界 | 空技留下的裂口可以被再次触发 |
| 音 | 余韵 | 音技的效果在结束后仍持续一段时间 |
| 时 | 残响 | 时技结束后以较弱的效果再重现一次 |

### 5.3 单技变种的例子

| 灵能技 | 变种 | 效果 |
|---|---|---|
| 赤星 | 连珠 | 一次链接连发三枚较小的赤星 |
| 履霜 | 冰镜面 | 冻出的冰面会反射雷系灵能技 |
| 列缺 | 回环 | 最后一跳回到第一个目标 |
| 扶摇 | 携行 | 可以带一名队友一起升空 |
| 壁立 | 拱桥 | 石壁横向生成,可作桥 |

### 5.4 无相灵种

**无相灵种**是没有元素属性的灵种,是这个世界上最稀有的东西之一。

- 融合后获得**一次额外的觉醒机会**,不占大阶突破给的名额。觉醒规则与平时相同(引导或随机,见设计文档 3.2)。
- 这是突破元素数量上限的唯一途径。常人一生四种元素,「双生灵核」八种;只有靠无相灵种,理论上才可能集齐全部十四种。
- 主角与 NPC 都可以使用。
- **没有人知道它的存在。** 没有典籍记载,没有 NPC 会提起,没有任务指向它。玩家只能自己撞见。
- **它只在领主的秘境里。** 每一只领主级异兽的领地深处都有一处秘境,无相灵种是领主守着的宝物。要拿到它,就得在领主的眼皮底下把它抢走。
- **正常情况下这不可能。** 领主寸步不离,秘境里是它的全部部属。只有当领主遭遇特殊的变故(离巢、重伤、与另一只领主相争)时,才有一线机会;即便如此也是九死一生。
- **第一篇不会出现无相灵种。** 这种层次的奇物只在强大领主的秘境里。云溪是小地方,衔烛守着的只是一枚中阶的火系灵种「地火」。无相灵种留待后续篇章。

### 5.5 自用,还是送人

灵晶、灵种、残篇、灵具、药剂,以及无相灵种,主角都可以自己用,也可以**赠予 NPC**。NPC 会得到与主角相同的增幅,并在并肩作战时用出来。规则见设计文档 8.5。
