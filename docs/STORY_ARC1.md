# 第一篇《云溪》剧情大纲

> 状态:**v0.5 草案**。世界观、系统规则见 [设计文档](DESIGN.md),灵能技见 [元素进阶与灵能技](ELEMENTS.md);本文只写第一篇的剧情、抉择与结算。
> 标记说明:**【必出】** 主线固定发生;**【条件】** 满足条件即发生;**【概率】** 自由探索时随机触发。

---

## 1. 基调与前提

- **主角是来自平行时空的穿越者。** 那个世界也有云溪、有同一个家、同一批人,只是没有灵能。主角醒来时成了这个世界的自己,云溪学院的一名高一学生。**人和地方都认得,规则全然陌生,而且处处有出入。**
- **主角在宏观上并不强。** 第一篇自始至终是见习灵能师。主角能赢下的是眼前的一场战斗、能救下的是眼前的几个人;城市的存亡不由主角决定。
- **云溪守不住。** 这是既定的结局。玩家决定的是:谁活着上了车,多少人走出了云溪,以及主角带着怎样的名声、秘密和亏欠离开。
- **选择比战力更有分量。** 主角真正能撬动世界线的,是知道什么、告诉谁、救谁、放弃谁。

## 3. 人物

第一篇中**有名有姓的角色都可能阵亡**,除非下表注明"固定"。存亡条件汇总见第 12 节。

### 两个世界的出入

主角认识下面的每一个人,但认识的是另一个世界的他们。游戏内的"两界札记"会逐条记下主角发现的出入。

| 人或事 | 主角原来的世界 | 这个世界 |
|---|---|---|
| 父亲 | 六年前死于一场车祸 | 守备队员,六年前在镜沼"殉职"。**死因不同,是全篇第一处要紧的出入** |
| 母亲与面馆 | 在老城区那条街上开面馆 | 一样。只是灶台烧的是火系灵纹 |
| 安安 | 十岁的妹妹,想当警察 | 十岁的妹妹,想进守备队 |
| 阿蘅 | 同桌,最好的朋友 | 一样。主角在这个世界里唯一"原封不动"的人 |
| 杜若 | 阿蘅的哥哥,在外地上大学,过年回来 | 三年前离家,下落不明 |
| 纪昭 | 年级第一,和主角交情不错 | 年级第一,与这里的"主角"几乎没说过话 |
| 方蔚 | 班主任,教物理 | 班主任,教实训 |
| 韩维 | 和蔼的教务主任,父亲去世后帮主角家办过助学金 | 同样和蔼。**主角会本能地信任他** |
| 顾松年 | 早已退休的老校长,只在校庆上见过 | 院长,云溪仅有的两位灵能大师之一 |
| 沈砚 | 父亲的朋友,开修车铺 | 父亲当年的队友,守备队东门队长 |
| 临江 | 入海口的大城市,外婆家在那里,每年暑假都去 | 二十年前陷落的沉城。外婆一家没能出来 |
| 海 | 小时候去游过泳的地方 | 没有人敢靠近 |
| 高考 | 一场考试 | 文考与武考,考不好可能会死 |

这些出入有三种用处:

- **线索**:两个世界不一样的地方,往往是这个世界出过事的地方。父亲的死因、杜若的去向、临江的命运,顺着出入查下去都通向主线。
- **陷阱**:主角对韩维的信任来自另一个世界。第一章"天赋说不说"的抉择里,"正式上报"之所以看起来稳妥,正因为经手的人是他。
- **破绽**:主角知道一些不该知道的事,也不知道一些"自己"本该知道的事。说漏嘴会被身边的人察觉,阿蘅是最先觉得主角"变了"的人。

## 4. 序章:异乡人

**时间**:启灵前一个月。**主角**:未启灵,没有灵能技。

### 开场

主角在原来世界的最后记忆模糊不清。再睁眼时坐在同一间教室、同一个座位上,同桌还是阿蘅,讲台上还是班主任方蔚。只是黑板上写的不是物理公式,而是"灵能守恒三定律"。

放学后回家的路上,玩家在一面橱窗玻璃前**选择性别、姓名与外观**(两个世界的主角长得一样)。路是认得的,家是认得的,开门的母亲也是认得的。直到晚饭时安安说起"爸爸巡逻的那片沼泽",主角才第一次意识到:这里不是家。

这个世界的"自己"留下的记忆只有碎片。主角有的是另一个世界十六年的完整记忆,它大体上管用,偏偏在要紧处不管用。

### 这一个月

没有战斗。主角以一个普通学生的身份在城内自由活动,一边学这个世界的规则,一边核对它与记忆的出入。这也是玩家的教程。

| 可以做的事 | 得到什么 |
|---|---|
| 上理论课、去图书馆 | 理论知识(决定结业考成绩,并解锁图鉴条目) |
| 在面馆帮忙、陪安安 | 家人的好感度;旧城区街坊的面孔(终章会再见到他们) |
| 体能训练 | 体力上限 |
| 照着课本练吞吐法的呼吸、在纸上描灵链的走向 | 还没启灵,吸纳不了灵能,也连不出灵链;但启灵后上手会快得多 |
| 逛四个城区 | 重新认识那些"认识"的人(沈砚不开修车铺了);了解公会、守备队;记下一条条出入 |
| 旁听顾松年的公开课并留下提问 | 顾松年的信任(影响第一章的选项) |
| 登上东门城墙 | 第一次望见海与沉城。白鹭在这里讲起二十年前的临江,以及"海里的那位" |

### 事件

- **【必出】深夜的结界塔**:某晚路过东门塔,看见一个人影在塔基的灵纹上动手脚。主角此时毫无战力。
  - *上前喝问*:人影逃走,落下一枚破壁会的徽记;对方记住了主角的脸。
  - *悄悄去找守备队*:沈砚带人赶到,记下主角一功;破壁会此后行事更隐蔽。
  - *装作没看见*:没有即时后果;第二章调查结界闪断时少一条线索。
- **【概率】面馆的赊账客**:一个受伤的猎人想赊一碗面,林晚拿不定主意,看向主角。帮与不帮,决定了老秦日后对主角的第一印象。

### 结尾

启灵前夜,一家三口吃晚饭。安安问:"你明天会觉醒什么?"

林晚没有问。十个人里有八个什么也觉醒不了,这孩子的理论成绩又只是中下。她只说,觉醒不了也没关系,面馆总要有人接。

## 5. 第一章:启灵

**时间**:启灵日,及随后的暑假。**主角**:见习下位。

### 启灵仪式【必出】

全年级近千人在学院礼堂依次将手按上启灵石。**大多数人的手放上去,石头没有任何反应。** 他们默默走下台,从此与灵能无缘。礼堂里的气氛就是这样一点一点沉下去的。

1. **纪昭**在主角之前上台,觉醒雷系,并当众显现天赋「疾咏」。全场轰动。衡州招生官温叙当场起身,递上衡州学府的预录取书。所有人都看到了:**天赋者会在显现的那一刻被带走,前途无量。**
2. 轮到主角。启灵石亮了。**觉醒哪一种元素是随机的,玩家不能选择**:可能是人人称羡的雷与火,也可能是被叫作"修城墙的"岩。台下的反应、老师的眼神、日后的待遇,都从这一刻起不一样。
3. 手离开石头的瞬间,主角体内的**天赋**显现(随机抽取)。启灵石只测元素,测不出天赋。**此刻只有主角自己知道。**

### 抉择:说,还是不说【必出】

这是第一篇第一个影响深远的决定。

| 选择 | 得到 | 代价 |
|---|---|---|
| **正式上报** | 进重点班;学院按月配给灵晶与灵纹;学院静室与训练场优先使用;顾松年亲自指点灵链;衡州预录取;守备队暗中保护 | 档案经韩维之手,**归潮当天就知道了**。此后袭杀事件进入事件池;主角的行动受到关注,难以私下接触破壁会 |
| **只告诉顾松年**(需序章取得他的信任) | 顾松年不入档,私下指点,提供少量资源 | 资源远不如正式上报;顾松年因此对学院内部起了疑心(提前埋下揭露韩维的线索) |
| **只告诉阿蘅** | 阿蘅的好感度大幅提升;一个可以完全托付的队友 | 没有任何资源;阿蘅此后会为守住这个秘密承担风险 |
| **谁也不说** | 完全的自由,归潮不知道主角的存在 | 普通学生的待遇,灵晶一切靠自己去找;日后若在实战中显露越阶战绩,会被动暴露 |

- 天赋为「双生灵核」时,启灵石只亮起了一种元素;第二种是手离开石头之后才在体内醒来的,没有人看见。隐瞒意味着平时只能在人前使用一种元素,第二种元素的灵晶也只能私下去找。
- 天赋为「异核」时,进阶元素本身藏不住(启灵石会亮),等于被迫上报;但云溪没有进阶元素的灵晶可以配给,受重视却没东西可练。
- 隐瞒不是一次性的。之后每一次在旁人面前越阶取胜,都会累积**暴露度**(见 11.2)。

### 结业考与分班

启灵同周举行高一理论结业考(题目来自序章的课程)。觉醒者升入灵能班,未觉醒者转入普通科,从此是两条路。那些没能觉醒的同学,主角以后会在面馆、码头、车站再见到。

在觉醒者之中,**理论成绩 + 元素的世俗评价 + 是否上报天赋**共同决定分班:重点班实训更多、有灵晶配给;普通班更自由、无人过问。

### 暑假

- **第一次修炼**:启灵当晚在家里第一次运转吞吐法,第一次亲手连出一条灵链。没有人能替主角做这件事。
- **第一次实训**:方蔚带全班到竹海边缘。战斗、当场链接灵链、元素与环境互动、队友配合的教学。全班都在失手,这很正常。
- **学生执照**:在猎人公会登记,可以接见习委托。老秦带主角走第一单。
- **副职业**:可以开始拜师入门(猎兽师、探脉师、铸器师、铭纹师、炼药师、结界匠,最多两门)。
- **回家**:把第一枚兽核带回面馆的那个晚上。

### 章末【必出】

实训返程途中,东门结界塔在所有人眼前闪断了几秒。

**【条件】纪昭遇袭**:纪昭启程去衡州的前夜,拔苗人动手。

- 主角是否在场,取决于此前是否与纪昭有过往来(同班、切磋、或接受了他的送行邀约)。
- *出手相救*:一场主角打不赢的战斗,目标是拖到守备队赶来。成功则纪昭重伤存活、推迟赴衡州,成为主角的同伴人选;主角的战力被人看见,暴露度上升。
- *去喊人*:来得及与否看距离与运气,纪昭可能重伤,可能身亡。
- *不在场*:纪昭身亡。

无论结果如何,全城都明白了一件事:**天赋在这个世界上既是通行证,也是催命符。**

## 6. 第二章:修行

**时间**:高二全年。**主角**:见习下位 → 中位。沙盒全面开放。

### 主线:闪断

1. 结界塔闪断越来越频繁。祁闻以课题的名义,请学生帮忙在各塔与哨站采集读数。
2. 随沈砚修复第一座哨站(竹海哨),学会哨站系统。
3. 读数显示闪断不是老化:有人在按固定的节律干扰塔基。序章若留下了破壁会的徽记,这里直接对上。
4. 追到镜沼深处的一处破壁会据点,人去楼空,只留下一份结界塔的内部检修日程。**这份日程只有学院教务处才有。**

### 这一年的生活

- **学业**:理论课与实训照常进行,期中、期末各有一次实战考核。
- **修炼**:吞吐、练灵链、冲关,全部要亲手做。城里灵能稀薄,想练得快就得带着灵晶去荒域的灵脉。
- **灵晶**:这一年最缺的东西。配给不够用,市面上的又贵又少,好的根本没有卖。探脉、狩猎后炼化兽核、做副职业换钱,各凭本事。
- **组队**:同学阿蘅、石敢、陆棠,公会的老秦可以入队。猎队的规矩是满编出行,但主角可以自己决定带几个人,甚至独行(规则见设计文档 8.5)。
- **势力**:公会、守备队、学院三条路线开放。
- **巢主「断尾」**:竹海的头领级。这一年里它是主角头顶的一座山,能否讨伐、带谁去、死不死人,全看玩家。

### 上报线与隐瞒线的分歧

| | 上报线 | 隐瞒线 |
|---|---|---|
| 资源 | 配给灵晶、灵纹、专人指点 | 委托、狩猎、探脉、副职业、黑市 |
| 关键事件 | **【必出】第一次夜袭**:拔苗人在主角回家路上动手。主角打不过,只能周旋到巡夜的沈砚赶来。若有队友同行,队友有阵亡风险 | **【条件】被看见的那一战**:主角第一次越阶取胜时,若有外人在场,对方会来问。封口、坦白或搪塞 |
| 家人 | 面馆门口多了守备队的暗哨;林晚开始失眠 | 家里一切如常 |

### 家庭线

**【条件】父亲的铭牌**:在镜沼探索到一定深度后,找到一处六年前的巡逻队遇难地。主角可以把父亲的身份铭牌带回家。沈砚看到铭牌上的刀痕后沉默了很久:那不是异兽留下的。(伏笔:父亲当年撞见了不该看见的人。第三章揭晓。)

### 章末

内部日程这条线索指向学院里有内鬼。祁闻让主角不要声张。

---

## 7. 第三章:暗流

**时间**:高二末至高三上。**主角**:见习中位 → 上位。烬岭开放。

### 主线:内鬼

1. **阿蘅的哥哥**:追查破壁会时遇到杜若。他认出了妹妹的同桌。通过他,主角第一次见到**渡者**。
2. **渡者的说法**:他不否认干扰结界塔,但坚称是在"给土地松绑"。他给主角看了一样东西:一张烬岭的灵能分布图,逐年变淡。他没有说谎,但也没说全。
3. **日程的来源**:渡者手里的检修日程是一位"同情者"提供的。他不知道那人是谁。
4. **锁定韩维**:线索的拼法取决于此前的选择。
   - 上报线:主角的档案只经过三个人的手,而拔苗人知道得太快。
   - 告诉顾松年线:顾松年早已暗中排查,把名单缩到了两个人。
   - 隐瞒线:靠父亲铭牌上的刀痕、镜沼据点的风系残留,以及闻筝的帮助。
5. **父亲的真相**:六年前,主角的父亲在镜沼撞见韩维与归潮的人交接,被灭口。

### 初潮【必出】

主角还没来得及揭发,韩维先动了手。一个雷暴夜,他同时瘫痪了两座结界塔,数只头领级带着兽群涌向缺口。

- 第一次围城战(规则见设计文档第 10 节)。岳峙与正阶们对付头领,见习们守街巷、救人。
- 主角决定带小队守哪个城区。**这一仗里主角的努力是有用的**:守住的城区保得住。
- 战斗中段,韩维趁乱去启灵档案室销毁记录,并试图对顾松年下手。
  - *主角赶到*:拖住韩维,等顾松年出手。韩维被擒或被杀。
  - *主角没有去*(选择了守城区):顾松年负伤(终章能支撑的时间缩短),韩维逃脱,终章时他会带着归潮的人回来破坏灵轨。

### 初潮之后

- 失守的城区留下损伤,需要重建。初潮中阵亡的队友与街坊不会回来。
- 归潮的存在公之于众。岳峙下令**把四座结界塔全部升到最大功率**。城里的人都松了一口气。
- 只有渡者、祁闻和读过那张分布图的主角知道这意味着什么。

## 8. 第四章:溯源

**时间**:高三。**主角**:见习上位。沉城与烛渊外缘开放。

### 主线

1. **沉城**:白鹭要回一趟临江,取一样二十年前没来得及带走的东西。她问主角去不去。
   - 沉城遍地头领级,这是一次潜行。主角可以带队友,但人越多越容易暴露,且有阵亡风险。
   - 在临江结界总控室找到当年的运行记录:结界塔功率与周边灵能的此消彼长,白纸黑字。
   - 白鹭讲述那一夜:结界全灭之后,海面隆起,"那位"只是看了一眼,所有异兽都伏在地上。它给了人类一个潮汐的时间离开。
2. **烛渊**:沈砚奉命侦察烬岭深处,带上了主角。在火山口边缘,主角第一次看见**衔烛**。它在挪窝。它身下的土地已经是灰白色的。
   - 细心的玩家会注意到一件没人解释的事:衔烛挪开的那一刻,火山口最深处有一点不属于任何元素的光。沈砚没看见,也没有任何人提起。「界感」天赋者、探脉师、带着闻筝同行的玩家会看得更清楚一些。**这是全篇唯一的提示,没有任务,没有记录。**
3. **渡者的坦白**:临江那一夜,是他擅自降低结界功率想验证自己的理论,被兽潮钻了空子。他这二十年是在赎罪。主角可以告诉他:他的"同情者"是归潮。

### 抉择:真相的去向【必出】

主角手里有三样东西:临江的运行记录、烬岭的灵能分布图、衔烛正在移动的目击。告诉谁?

| 选择 | 后果 |
|---|---|
| **交给岳峙** | 三样证据齐全时他会相信:立即向衡州求援,秘密预备疏散(**疏散准备度大幅提高**)。但他拒绝降低结界功率,理由是来不及了。证据不全则被斥为动摇军心 |
| **交给祁闻** | 学院悄悄着手研究并说服顾松年;疏散准备度中等提高;资料得以完整带出云溪(影响后续篇章) |
| **交给渡者** | 破壁会试图强行降低功率,与守备队冲突;杜若的生死由此决定;疏散准备度不变 |
| **公之于众** | 全城恐慌,一部分人提前逃离(撤离人数提高),但城防与秩序下降,主角会被追究 |
| **不说** | 没有任何准备。终章的开局是最坏的 |

可以依次告诉不止一方,但每多一方,消息走漏和冲突的风险就多一分。

### 这一年的其他线

- **闻筝**:主角发现她能"看见"灵能。三年前她选择了隐瞒,因此留在了云溪,也因此活着。她是主角唯一能谈论这件事的人。是否劝她站出来、是否邀她入队,由玩家决定。
- **禾生**:牧场的牲口对他言听计从。他不知道这叫天赋。
- **巢主「铁脊」**、**「沉灯」**、**「末班车」**:可选的极限讨伐。
- **备考**:高考将近。文考看图鉴与理论,武考看真本事。

## 9. 第五章:高考

**时间**:高三末。高考分文考与武考,成绩决定能去哪座城市的学府。

### 文考

一天。题目出自玩家两年来真正学到的东西:异兽的习性与弱点、元素反应、结界常识。图鉴越完整,分数越高。

### 武考

三天两夜,考场设在烬岭外山。以猎获的兽核计分,可以组队(每队最多四人),独行有加权。方蔚等正阶老师监考。

- 第一天:正常的考试。玩家可以全力刷分,也可以留力。
- **第二天夜里【必出】**:烬岭深处火光冲天。成群的异兽从山上奔逃而下。**它们不是冲着人来的,它们在逃。** 衔烛出渊了。

### 撤退

考试终止。两百多名考生散布在外山各处,方蔚下令向山脚哨站集结,自己带几名老师殿后。

主角此时的位置、身边的人、还剩多少灵能,全是第一天自己的选择造成的。

- **沿途的同学**:几路考生被兽群截住。主角救得了一路,救不了每一路。石敢、陆棠若不在主角队中,会各自出现在其中一路。
- **回头,还是不回头**:快到哨站时,山上传来方蔚的霜环炸开的声音。回去接应意味着面对头领级;不回去,方蔚阵亡。回去了,也未必救得下。

### 另一条路:烛渊【隐藏】

衔烛离开了它守了不知多少年的地方。此刻的烛渊是空的。

这件事没有任何人告诉主角,游戏也不会提示。只有记得第四章那一点光、并且在所有人往山下跑的时候**逆着兽群往山上走**的玩家,才会走到这里。

- **烛渊的秘境**:衔烛盘踞之处的最深处。领主不在,它的部属还在:数只头领级,和满地还没凉透的熔岩。见习的主角打不过其中任何一只,只能靠地形、时机和手里那个见习中位的通行技一路躲进去。倒下就是前功尽弃;带队友同去,队友几乎一定会死。
- **无相灵种**:秘境中心,衔烛守着的东西。没有人知道它是什么,主角拿到手时也不知道。它的用途要到融合的那一刻才显现(额外觉醒一种元素的机会,见 ELEMENTS.md 5.4)。
- **代价**:
  - 主角不在撤退的路上。沿途的同学与方蔚只能听天由命。
  - 主角赶回云溪时,灭城之夜的前两个时段已经过去。旧城区的撤离、东门的防线,主角都没赶上。
  - 衔烛感应到宝物被夺。它的攻势一度停滞,回头望了烛渊很久(岳峙与顾松年因此多喘了一口气),随后更加狂暴,而且**它记住了主角的气息**。
- **得手之后**:自己留着,还是给别人。在这一夜之后的列车上,它可能是整个云溪带出来的最贵重的东西,也可能是主角一辈子说不出口的事:别人在救人的时候,主角在抢东西。

这是第一篇里唯一一次得到无相灵种的机会。领主寸步不离自己的秘境,这样的变故可遇不可求。

### 章末

幸存的考生退回城内。东门在身后合上。北面的天是红的。

## 10. 终章:大潮

**时间**:一夜,从黄昏到黎明。**唯一真实计时的章节。**

### 局势

| 方面 | 情况 |
|---|---|
| 衔烛 | 领主。岳峙与顾松年出城迎战,两个人拼死才拖得住它 |
| 兽潮 | 数十只头领级与数不清的游荡级,从北、东两面压向城墙 |
| 守军 | 四十余名正阶、千余名见习,分守四个城区 |
| 疏散 | 平民经灵轨撤往衡州。列车班次有限,车站在河港区 |
| 援军 | 衡州的宗师必须留守牵制自己那一位君主,只派得出三名灵能大师,天亮才能到 |

正阶与见习改变不了这一夜的结局。但每一条街能多守一刻钟,就能多走一车人。

### 结构

一夜分为六个时段。每个时段城中有数处同时告急,**主角一个时段只来得及去一两处**。没去的地方,按该处的防御评分、此前的世界线和运气结算。

| 时段 | 局势 | 告急之处(示例) |
|---|---|---|
| 一、黄昏 | 兽潮接城,结界尚在 | 旧城区组织撤离(家人、街坊);学院区转移研究资料 |
| 二、入夜 | 东门塔承压最重 | 东门防线(沈砚、石敢);河港区车站秩序 |
| 三、深夜 | 第一处缺口出现,兽群入城 | 旧城区巷战;公会猎人断后(老秦、陆棠);韩维若在逃,此时破坏灵轨 |
| 四、子夜 | **顾松年燃尽灵核【固定】**。全城都看见北面那道光亮起来,又灭下去 | 学院区失守在即(祁闻、闻筝);渡者请求主角帮他做一件事 |
| 五、凌晨 | 岳峙独自拖着衔烛;结界塔相继熄灭 | 最后几班列车;掉队的人;队友各自的生死关头 |
| 六、破晓 | 四塔全灭 | 最后一班车 |

### 主角在这一夜能做什么

- **游荡级的兽群**:打得过。清出一条街,这条街的人就能走。
- **头领级**:打不赢。目标只有一个,**拖住它**,拖到身后的人走完。
  - 主角该小阶圆满、手法过硬、带着活着的队友:能勉强拖住一只。
  - 积累不足、队友零落:拖不住。只能选择带人绕路(更慢,更多人掉队),或者眼睁睁看着。
- **如果主角倒下**:被人拖到后方,这个时段剩下的事全部错过。主角不会死,但这一夜不等人。
- **如果主角去了烛渊**:时段一、二不在城中,从时段三才加入。衔烛会在这一夜里分神寻找夺走它宝物的气息,主角所在的告急点更容易引来头领级。
- **上报线的额外压力**:拔苗人在这一夜回来找主角。同时,岳峙留给主角的两名护卫也在。
- **隐瞒线的最后一次选择**:在全城人面前全力出手,还是继续藏着。

### 渡者的请求【条件:渡者存活】

渡者想去东门塔,把功率降下来,把灵能还给土地。他知道来不及救这座城,但也许能让衔烛停下来。他一个人到不了那里。

- *护送他*:主角放弃这一时段的其他告急点。若成功,衔烛的攻势减缓,岳峙存活的可能提高,渡者死在塔下。
- *拒绝*:渡者独自前往,死在半路。

### 无岸【必出】

四座结界塔全部熄灭的那一刻,所有声音都停了。

海面隆起。城里的每一只异兽都伏在了地上,包括衔烛。**无岸**没有上岸,也没有出手。所有人在同一瞬间明白了同一件事:这片土地不再属于人类,潮水退尽之前必须离开。

它的目光扫过整座城,**在主角身上多停了一瞬。**(后续篇章的伏笔:主角的来历。)

衡州的三名灵能大师此时赶到。他们没有向海的方向看哪怕一眼,接应下还活着的人,掩护最后一班列车发车。

## 11. 抉择与世界线

### 11.1 事件的结构

每个事件由五部分组成:**触发条件 → 情境 → 选项 → 即时结果 → 世界线标记**。

- 选项通常 2–4 个。部分选项只在拥有特定元素、天赋、队友或声望时出现。
- 即时结果可能是战斗、奖励、损失、有人受伤或死亡。
- 世界线标记不显示给玩家。后果可能在几章之后才到来。
- 概率事件不可通过读档反复刷取结果:事件一旦触发,其内容在该存档中即已确定。

### 11.2 世界线变量

| 变量 | 含义 | 主要影响 |
|---|---|---|
| 暴露度 | 外界对主角天赋与真实战力的了解程度 | 资源与关注;归潮袭杀事件的频率;下一篇各方对主角的态度 |
| 疏散准备度 | 云溪为撤离做了多少准备 | 终章撤离人数的基数 |
| 城防 | 四个城区的防御评分与损伤 | 两次围城战中各城区撑多久 |
| 归潮渗透 | 韩维是否伏法、归潮在城内还剩多少人 | 终章灵轨是否被破坏 |
| 人物状态 | 每个有名有姓者的生死、伤势、与主角的关系 | 终章各告急点的结算;下一篇谁还在 |
| 立场 | 主角把真相交给了谁 | 终章渡者线;下一篇的开局 |

### 11.3 概率事件示例

以下是事件池的一部分,用来确定写法与分量。完整事件池在实现阶段扩充。

| 事件 | 触发 | 选项与后果 |
|---|---|---|
| **被困的猎队** | 竹海,任意时间 | 一支猎队被犬群围在断崖下。*杀进去*:一场硬仗,救下的猎人日后在公会为主角说话,其中一人可能成为队友。*回城报信*:赶得及的话活一半。*捡走他们掉落的兽核离开*:一笔横财;若有人活下来,他认得主角的脸 |
| **尾随者** | 城内,夜间 | 有人跟了主角三条街。暴露度高时是拔苗人的眼线,低时是温叙派来观察的人,或者只是个小偷。主角不知道是哪一种。*甩掉*、*反跟踪*、*当面对质* |
| **幼兽** | 镜沼 | 一只失去母兽的苇蜥幼崽。*杀了取核*。*放它走*。*藏起来养*:它会长大。有「兽语」时可以驯服;没有的话,某一天它会咬人 |
| **便宜的灵晶** | 河港区黑市,隐瞒线更常见 | 价格只有市价一半的灵晶,还有市面上见不到的品类。*买*:修炼快得多;这些灵晶是从被归潮杀害的猎人身上搜来的,钱流向了归潮(归潮渗透上升)。*追查来源*:一条通向韩维的支线 |
| **逃兵** | 任一哨站 | 一名守备队新兵躲在哨站地窖里,求主角别说出去。*上报*、*帮他回家*、*劝他回队*。他是石敢的同乡 |
| **矿道** | 烬岭 | 采矿队被落石封在矿道里,而铁脊正在靠近。岩系可以开路,雷系可以启动矿道的旧升降机,否则只能硬守洞口。救出多少人取决于手段与时间 |
| **不该在这里的人** | 任一野外区域,第三章起 | 撞见破壁会成员正在哨站的中继塔上动手脚。*制止*、*放他走*、*问他为什么*。若此前已与渡者接触,对方会认出主角 |
| **同行者的请求** | 带队友出行时 | 一名队友想绕路去做一件私事(给家人采药、找失散的同伴、了结旧怨)。*答应*:好感度提升,途中有风险。*拒绝*:他可能自己去 |

### 11.4 奇遇

奇遇是小概率的特殊事件,带来寻常途径得不到的东西(规则见设计文档 3.12)。多发生在荒域深处、巢穴、遗迹、灵脉,以及副职业的活动中。

| 奇遇 | 触发 | 内容 |
|---|---|---|
| **灵种** | 极小概率;巢主的巢穴、沉城、烬岭深处的灵脉 | 一枚天然凝成的元素之种,通常有异兽守着,或者已经有别人盯上了。得手后要当场决定:自己融合(须与自己的元素相符)、留给队友、卖掉(一笔能改变全家生活的钱,也会引来觊觎)、或上交学院 |
| **残篇** | 小概率;遗迹、临江旧档案、老猎人的遗物 | 前人留下的某个灵能技的另一种链式。照着连成功一次,该技能获得变种 |
| **灵脉秘地** | 小概率;探脉时 | 一处无人知晓的高浓度灵脉。独占,还是告诉公会换声望 |
| **纯晶矿点** | 小概率;探脉师 | 矿点在一只头领级的活动范围内。能挖多少取决于胆量与脚程 |
| **高人指点** | 小概率;与特定 NPC 好感度足够时 | 老秦、白鹭、方蔚、顾松年各有一手压箱底的东西 |
| **幼崽** | 见 11.3"幼兽" | — |

第一篇里,一个勤于冒险的玩家大约能遇到两三次奇遇;灵种可能一次也遇不到。

**无相灵种不在奇遇池里。** 它没有概率,只有一个地点和一个时机(第 9 节"另一条路")。

### 11.5 自用,还是送人

主角得到的每一份资源、每一次奇遇,都面临同一个问题:自己用,还是给别人(规则见设计文档 8.5)。

- **给队友**:石敢多一袋岩系灵晶,也许就能在大潮前修到见习中位、学会升岩,东门的那段墙就多撑一刻。
- **给不在队里的人**:把沉城带回的光系纯晶送给顾松年,他在终章能多撑一个时段。把水系灵晶给沈砚,东门防线的评分会涨。
- **给错了人**:韩维也收礼,而且总是笑着收下。
- **谁也不给**:主角自己用掉,这一夜能拖住的东西也许就多一只。

没有正确答案。主角一个人再强也只是见习;但把资源分出去,就要承担他们死了、东西打了水漂的可能。

### 11.6 组队与伤亡

- 猎队的规矩是满编出行。主角可以不守这个规矩:带满三人、只带一人、或独行。
- 人多则稳,但战利品按人头分;独行所得全归自己,积累最快,也最容易死在外面。
- **队友会死。** 队友倒地后进入濒死状态,在限时内救起则重伤休养;救不起,或主角撤退时把他留下,就是永久阵亡。越阶讨伐和高潮位区域的风险最高。
- 队友阵亡会被记住:他的家人、同乡、其他队友的态度都会变。
- **天赋者极难遇到。** 寻常天赋万里挑一,且一经显现就被超级城市带走。留在云溪的天赋者只有隐瞒者与漏网者:闻筝、杜若、禾生。他们都不会轻易入队,玩家完全可能到通关都没有一个天赋者队友。

## 12. 第一篇结算

### 12.1 既定之事

无论玩家怎么做,以下不会改变:

- 云溪陷落,无岸现身,幸存者撤往衡州。
- 顾松年在终章牺牲。
- 衔烛没有被击败。
- 主角活着离开,位阶为见习上位。

### 12.2 存亡名单

队友与熟人的实力会直接计入各告急点的结算,包括主角赠予的资源给他们带来的提升;好感度决定他们在关键时刻愿意为主角做到哪一步。

| 人物 | 存活取决于 |
|---|---|
| 林晚、安安 | 终章时段一、三是否顾及旧城区;序章与平日积累的街坊关系(有人会帮忙带她们走) |
| 阿蘅 | 两年间是否在野外阵亡;终章是否把她留在了守不住的位置;杜若的结局 |
| 石敢 | 是否入队;东门防线的城防评分;主角时段二是否到场 |
| 陆棠 | 是否入队;武考撤退时主角救的是哪一路;终章公会断后 |
| 老秦 | 终章时段三主角是否去了河港区。他会自己选择留下断后,除非有人把他拉走 |
| 纪昭 | 第一章遇袭事件 |
| 方蔚 | 武考撤退时主角是否回头,以及拖不拖得住 |
| 闻筝、祁闻 | 终章时段四主角是否去了学院区;初潮时学院区是否守住 |
| 禾生 | 是否相识;牧场在城外,相识的话他会在大潮前带着牲口进城 |
| 沈砚 | 东门防线撑了多久;他会战至东门塔倒下 |
| 岳峙 | 疏散准备度(撤离越早完成,他越早得以脱身);渡者线;衡州援军抵达时他是否还站着 |
| 渡者 | 第四章的立场选择;终章固定死亡,但死在哪里、有没有意义由主角决定 |
| 杜若 | 第四章是否把真相交给渡者;阿蘅是否还活着 |
| 韩维 | 初潮时主角是否赶到档案室 |

### 12.3 撤离人数

云溪约八万人。最终走出云溪的人数在片尾逐项列出:

- **基数**:由疏散准备度决定(真相交给了谁、证据是否齐全)。
- **灵轨**:是否畅通(韩维是否伏法、哨站是否完好)。
- **四个城区各自撑了多久**:由城防评分、初潮的损伤与重建情况决定。
- **主角亲手带出的人**:终章每一个到场并守住的告急点。

### 12.4 带往下一篇的东西

- 存亡名单与各人对主角的态度。
- 主角的天赋是否已为人所知,以及知道的是谁。
- 高考成绩:文考分数、武考第一天的猎获,加上撤退与灭城之夜的战时记录折算。决定衡州哪一所学府接收主角,以及入学时的待遇。
- 结界塔真相的资料是否带了出来,在谁手里。
- 主角从家里带走的东西。
- 无相灵种(若得手):在谁手里,用了没有,以及衔烛是否记住了主角。

## 13. 尾声:归途

清晨,撤离列车驶出云溪。

车厢里有人在清点名单。镜头扫过座位:谁在,谁的位子空着,由这两年决定。

主角在车窗里最后看了一眼云溪。四座塔都黑了。海面平静,像什么都没有发生过。

**第一篇完。**
